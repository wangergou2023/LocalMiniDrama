# 附件：专业镜头语言辅助参考库

版本：2026-06-17

用途：作为 `screenplay.txt` 的附属参考材料，只辅助丰富镜头描述、运镜设计、动作细节、画面动效和导演思维。所有主规则全部以 `screenplay.txt` 为准。

---

## 0. 附件使用边界

本附件只做三件事：

1. 帮助 AI 选择更准确的景别、机位、构图、调度、运镜和剪辑思路。
2. 帮助 AI 把“画面”“动作细节”“特效细节”“镜头类型&景别&运镜”写得更具象、更有动效、更像影视分镜。
3. 帮助 AI 在不改变原剧情、不改变主文档格式的前提下，补充专业导演思维。

本附件不得做以下事情：

- 不新增输出字段。
- 不改变 `screenplay.txt` 的固定格式。
- 不改变主文档里的任何硬性规则。
- 不改变样例复刻要求。
- 不覆盖主文档里的风格适配、合规、对白、表情、校验规则。
- 不要求 AI 输出本附件的标题、表格或分析过程。

冲突处理原则：

```text
如果本附件与 screenplay.txt 有任何冲突，永远执行 screenplay.txt。
本附件只作为镜头语言和画面描述的参考库，不作为格式规则。
```

## 1. 导演思维：先判断镜头目的

写每个分镜前，先在内部判断这一镜的叙事功能。不要只把原文翻译成画面，要知道这一镜让观众获得什么信息。

每个镜头至少属于以下一种目的：

- 交代空间：让观众知道人物在哪里、谁和谁处在什么位置。
- 推进行动：让观众看清人物做了什么。
- 表达情绪：让观众通过表情、姿态、沉默和动作读懂心理。
- 强化冲突：让人物关系、压迫感、对立感更明确。
- 揭示信息：让关键道具、线索、真相或反转被看见。
- 制造悬念：先隐藏全貌，只给局部、声音、反应或画外信息。
- 完成衔接：让上一镜的动作、视线、情绪自然接到下一镜。

内部判断公式：

```text
镜头目的 = 剧情节拍 + 观众视点 + 角色状态 + 信息释放 + 情绪落点
```

可写入画面描述的表达方式：

- “镜头先停在角色紧绷的手指，再顺势带出他强压怒意的表情。”
- “镜头越过前景人物肩膀，压低视角聚焦对方逼近的姿态。”
- “镜头跟随角色视线转向门口，让观众先看到阴影再看到来人。”

## 2. 景别使用补充

`screenplay.txt` 已经定义景别名词，本附件只补充每种景别适合写什么内容。

| 景别 | 适合表达 | 描述重点 |
|---|---|---|
| 大远景 | 环境规模、孤立、压迫、开场交代 | 地点、天气、人物位置、空间层级 |
| 远景 | 人物与环境关系 | 走位、入口、距离、场面范围 |
| 全景 | 全身动作和站位 | 姿态、肢体动作、人物间距离 |
| 中景 | 对话、日常动作、关系变化 | 半身动作、表情初步变化、手势 |
| 中近景 | 情绪加压、对峙、重要对白 | 眼神、嘴角、眉头、肩颈紧绷 |
| 近景 | 情绪转折、关键反应 | 面部肌肉、呼吸、眼神焦点 |
| 特写 | 线索、道具、微表情、动作细节 | 手、眼睛、手机、门把、账单、杯子 |
| 大特写 | 极强情绪或关键证据 | 瞳孔、汗珠、指尖颤动、裂痕、文字 |

使用原则：

- 要看清动作，用全景或中景，不要用过近景别。
- 要看清心理，用中近景、近景或特写。
- 要交代空间，先给远景或全景，再进入人物细节。
- 要制造压迫，可从中景推进到中近景或近景。
- 要做反转，可先给特写线索，再切角色反应。

竖屏短剧补充：

- 竖屏中人物面部更重要，中近景和近景要写清表情颗粒度。
- 全景容易显得主体太小，必须补充明确站位和环境动作。
- 多人同框时要写清前后层次，避免人物挤在同一平面。

## 3. 机位与角度补充

| 机位/角度 | 情绪效果 | 适合场景 | 描述示例 |
|---|---|---|---|
| 平视 | 真实、中性、自然 | 正常对话、客观叙事 | 平视中近景，角色直视对方，语气克制 |
| 低角度 | 强势、威胁、压迫、掌控 | 逼问、登场、权力压制 | 低角度拍摄人物前倾逼近，阴影压住下半张脸 |
| 高角度 | 弱势、被审视、孤立 | 被质问、失落、被围观 | 高角度俯拍角色站在空旷大厅中央 |
| 过肩 | 对话关系、视线方向 | 正反打、谈判、审问 | 越过一方肩膀聚焦对方怒容，前景肩线虚化 |
| 主观视角 | 代入、发现、恐惧 | 看见线索、开门、窥视 | 以角色视线看向桌上账单，边缘轻微失焦 |
| 背后跟拍 | 沉浸、未知、跟随 | 进入空间、潜入、追赶 | 背后跟随角色穿过走廊，前方门缝透出冷光 |
| 侧面跟拍 | 行进感、速度、对峙 | 走路对话、追逐、并排行动 | 侧面跟拍两人快步穿过大厅，背景人群后退 |
| 鸟瞰/俯视 | 布局、命运感、被困 | 人群、空间关系、围堵 | 高机位俯拍人物被围在桌边，出口被遮挡 |
| 荷兰角 | 失衡、不安、异常 | 惊悚、精神崩溃、突发变故 | 轻微倾斜构图，角色身后的门框压迫画面 |

避免冲突：

- 不要同时写“低角度俯视”，除非空间关系非常明确。
- 不要写“近景展示全身动作”，近景适合面部和局部。
- 不要写“固定镜头快速跟拍”，固定镜头和跟拍是不同运动方式。
- 不要写“广角压缩空间”，压缩空间通常是长焦效果。

## 4. 构图与场面调度补充

构图的任务是控制观众视线，场面调度的任务是让人物关系和动作逻辑清楚。

常用构图：

- 中心构图：权威、压迫、仪式感、人物被锁定。
- 三分构图：自然、稳定、适合对话和日常叙事。
- 前景遮挡：门框、肩膀、玻璃、窗帘、绿植，制造窥视感和层次。
- 框中框：门、窗、镜子、柜台，表达隔阂、困住、被观察。
- 负空间：人物旁边留出空处，暗示威胁、孤独或等待变化。
- 引导线：走廊、桌沿、灯带、楼梯，把视线导向主体。
- 前中后景分层：前景道具、中景人物、背景环境同时提供信息。

场面调度要写清：

- 谁在前景，谁在中景，谁在背景。
- 谁主动靠近，谁后退，谁被迫停住。
- 角色视线指向哪里。
- 手部动作是否推动剧情。
- 道具是否处在观众能注意到的位置。
- 环境是否参与冲突，如门口围观者、桌面账单、手机亮屏、吧台遮挡。

可直接使用的描述句式：

- “前景用虚化肩膀压住画面，中景聚焦被质问者的克制表情，背景人群投来视线。”
- “角色站在画面右侧，左侧留出大片空位，门口阴影暗示新的压力即将进入。”
- “柜台横在两人之间形成视觉分割，强化对峙关系。”

## 5. 运镜补充：每一种运动都要有动机

运镜不要只写名称，要写清运动方向、速度、跟随对象和叙事目的。

| 运镜 | 作用 | 描述重点 |
|---|---|---|
| 固定镜头 | 克制、观察、让表演主导 | 人物在画面内移动，镜头不动 |
| 慢推 | 情绪加压、逼近真相 | 从中景推到中近景或近景 |
| 急推 | 冲击、惊讶、强刺激 | 对准关键表情或线索瞬间推进 |
| 拉镜 | 孤立、揭示环境、情绪抽离 | 从人物拉开，露出旁人或空间 |
| 横摇 | 跟随视线、揭示画外信息 | 从一个信息点摇到另一个信息点 |
| 竖摇 | 揭示高度、身份、压迫 | 从脚步/手部上摇到脸或建筑 |
| 跟镜 | 沉浸、速度、行动连续 | 跟随角色前进、后退或穿越空间 |
| 环绕镜 | 情绪旋涡、关系变化 | 围绕人物半圈或一圈，背景转动 |
| 升降镜 | 权力变化、空间揭示 | 镜头升起露出人群或降低贴近动作 |
| 微晃动镜 | 紧张、临场、失控 | 轻微手持感，不要过度晃到看不清 |
| 甩镜 | 快速转移注意力、强节奏转场 | 甩向新动作点或新人物反应 |

运镜动机模板：

- 因为角色移动，所以镜头跟随。
- 因为压力增强，所以镜头慢推。
- 因为要揭示旁观者或环境，所以镜头拉远。
- 因为角色看向画外，所以镜头横摇揭示。
- 因为情绪失控，所以加入轻微手持晃动。
- 因为关系逆转，所以用环绕或机位高度变化。

更好的写法：

```text
中近景微推运镜，镜头从林晚平静的肩线缓慢推进到她克制的眼神，突出她面对质问时的冷静压迫感。
```

差的写法：

```text
电影感运镜，高级镜头。
```

## 6. 画面动效强化

视频提示词要让运动可见。不要只写“动态感”，要写出什么在动、怎么动、为什么动。

动效公式：

```text
主体动作 + 镜头运动 + 前景掠过 + 背景视差 + 光影变化 + 物理细节
```

可补充的动效类型：

- 人物：转头、停顿、后退、逼近、抬手、握拳、指向、低头、抬眼。
- 表情：眉头收紧、眼尾上挑、嘴角下压、鼻翼翕动、喉结滚动、眼神闪避。
- 服饰：衣摆晃动、袖口摩擦、领口随呼吸起伏。
- 环境：灯光闪烁、门缝透光、人群后退、窗帘晃动、桌面反光。
- 粒子：烟尘、雨滴、水花、热气、纸张飘动。
- 声画联动：脚步声接近时镜头轻微转向，拍桌声后给反应镜头。

示例：

```text
镜头低机位跟随男人快步逼近吧台，前景桌角迅速掠过，背景客人停下动作转头围观，男人外套下摆随步伐摆动，吧台灯光在他紧绷的脸上形成硬阴影。
```

## 7. 连续性辅助检查

`screenplay.txt` 已经规定上下分镜必须闭环。本附件只提供内部检查角度，检查结果应融入原有字段，不新增字段。

每个镜头接下一镜前检查：

- 轴线：人物左右关系是否稳定。
- 眼线：上一镜角色看向哪里，下一镜是否接到被看的对象。
- 动作：上一镜动作结束点，下一镜是否自然延续。
- 表情：情绪是递进、压住、爆发还是回落。
- 道具：手机、账单、杯子、门把手等位置是否改变。
- 光线：同一空间内光源方向是否一致。
- 声音：对白、脚步、拍击、环境声是否能作为衔接钩子。
- 景别：是否连续多个镜头过于重复，或突然跳到不合理景别。

常用衔接方式：

- 视线匹配：角色看向画外，下一镜切到他看的对象。
- 动作匹配：抬手开始在上一镜，落手完成在下一镜。
- 声音桥：先听到脚步声，下一镜再出现来人。
- 反应衔接：关键台词后切听者表情，让情绪落地。
- 插入衔接：用道具特写连接空间或遮盖时间压缩。

## 8. 常见短剧场景镜头策略

### 8.1 对话和质问

基础组合：

- 建立镜头：先让观众知道两人位置和冲突空间。
- 过肩正反打：保持眼线和对峙关系。
- 中近景：承接情绪升级和关键台词。
- 反应镜头：让被质问者、围观者或第三方的态度被看见。
- 细节特写：拍手指、账单、手机、桌面、门口人影等关键线索。

增强方式：

- 强势一方：低角度、前倾、占据画面更大面积。
- 弱势一方：高角度、后退、被柜台/门框/人群压住。
- 克制反击：固定镜头或慢推，突出平静表情下的力量。

### 8.2 悬疑和反转

常用顺序：

1. 先给异常细节。
2. 再给角色察觉。
3. 再给对方反应。
4. 最后揭示全貌。

可用镜头：

- 门缝、影子、反光、手机屏幕、桌面物件特写。
- 慢推到角色眼神，表现他意识到不对。
- 轻微手持或慢横摇揭示画外人。

### 8.3 冲突爆发

镜头要先可读，再加速：

- 先用中景或全景交代谁靠近谁。
- 再切手部、表情、道具细节。
- 再切对方反应。
- 最后用更近景别承接情绪爆发。

避免全程特写，否则观众看不清空间和动作因果。

### 8.4 情绪压抑和沉默

适合：

- 固定镜头。
- 慢推。
- 低声环境声。
- 近景表情微变化。
- 手部细节，如握紧杯子、指尖停顿、袖口轻颤。

描述重点不是“悲伤”，而是可见的身体细节。

### 8.5 人物登场

三种方式：

- 威压登场：先脚步声，再低角度拍人物进入，背景人群让开。
- 神秘登场：先影子、手、背影，再切正脸。
- 反差登场：先铺垫紧张，人物出现后用平视中景制造落差。

## 9. 拉片方法：把好镜头变成可复用描述

拉片时不要只记剧情，要记导演手段。

记录项：

- 这个镜头解决了什么叙事问题。
- 用了什么景别和机位。
- 人物在画面中怎么站、怎么动、怎么看。
- 摄影机为什么移动。
- 光线和前景如何制造氛围。
- 剪辑点为什么放在这里。
- 这个镜头可复用到什么短剧场景。

提炼模板：

```text
在【剧情情境】中，用【景别 + 机位 + 构图 + 运镜】先让观众看到【信息 A】，再意识到【信息 B】，从而产生【情绪效果】。该方法可复用于【相似场景】。
```

示例：

```text
在角色强压怒意的情境中，用中近景固定镜头保持克制，只让手指和眼神出现细微变化，使沉默比台词更有压力。该方法可复用于谈判、审问、反击前停顿。
```

## 10. 镜头语言反面清单

避免以下问题：

- 只写“电影感”“高级质感”，没有具体景别、机位、构图、动作。
- 每个镜头都推近，导致节奏单调。
- 对话没有建立空间，正反打左右关系混乱。
- 特写镜头要求展示全身动作。
- 远景镜头要求看清细微表情。
- 横摇、横移、跟拍混用，但没有说明镜头是否移动位置。
- 打斗或争执全靠碎片特写，观众看不清谁对谁做了什么。
- 悬念场景过早拍清答案。
- 表情只写“生气、难过、震惊”，没有眉眼、嘴角、呼吸、姿态细节。
- 运镜只写名称，不写方向、速度、对象和动机。
- 动效只写“动态模糊”，没有人物动作、前景、背景、光影和物理细节。

## 12. 一页速查

镜头选择：

- 要交代地点：远景、建立镜头、深焦、稳定构图。
- 要看动作：全景/中景、侧面或三分之四角度、保持方向。
- 要看关系：双人镜头、过肩、正反打、构图距离。
- 要看心理：近景、慢推、浅景深、反应镜头。
- 要制造悬念：局部特写、遮挡、负空间、慢横摇、画外声源。
- 要表现压迫：低角度、中心构图、前景遮挡、推近。
- 要表现弱小：高角度、远景、负空间、拉远。
- 要表现速度：跟拍、侧移、前景掠过、运动模糊、短镜头切换。
- 要表现失控：手持微晃、倾斜构图、焦点漂移、快速剪辑。
- 要表现余韵：静态镜头、空镜、拉远、环境声收尾。

运镜动机：

- 跟随 = 主体在移动。
- 推近 = 情绪或信息加压。
- 拉远 = 孤立或揭示环境。
- 横摇 = 发现画外信息。
- 横移 = 平行跟随或揭示空间层次。
- 环绕 = 关系变化或心理旋涡。
- 升降 = 权力、规模、发现。
- 固定 = 让表演、空间或沉默自己说话。

## 14. 拉片方法：不要只记“用了什么镜头”，要记“为什么此刻用”

拉片不是把镜头术语抄下来，而是把导演在每个叙事节点上的选择拆成因果链。每个镜头至少记录以下 8 项：

| 观察项 | 要回答的问题 | 可转写到 AI 分镜的方式 |
|---|---|---|
| 剧情节拍 | 这一镜推进了什么事件？ | “承接上一镜争执，角色终于说出关键信息。” |
| 信息释放 | 观众比角色多知道还是少知道？ | “先给观众看到门缝阴影，角色尚未察觉。” |
| 视点归属 | 镜头站在谁的立场看？ | “陆沉主观视角”“围观人群越肩视角”“冷静旁观视角” |
| 空间关系 | 人物、门、道具、出口在什么位置？ | “前景为陆沉肩膀，画面右后方是车厢门。” |
| 情绪曲线 | 情绪是升高、压低、冻结还是释放？ | “镜头缓慢推近，让压迫感逐秒增加。” |
| 动作接点 | 上一镜和下一镜靠什么接？ | “接上一镜抬手动作，下一镜切手机屏幕特写。” |
| 声音接点 | 对白、环境声、音效是否跨镜？ | “喇叭声先入画外，再切到工作人员。” |
| 画面策略 | 隐藏、揭示、对比、重复还是反转？ | “先用遮挡隐藏车厢全貌，只露出僵硬手指。” |

拉片记录公式：

```text
这一镜 = 叙事功能 + 观众视点 + 空间调度 + 情绪方向 + 信息释放方式 + 衔接方式
```

反向检查：

- 如果只写出“中景、推镜、冷光”，说明还没有拉出导演意图。
- 如果能写出“为什么此刻不能用远景/为什么必须先给反应/为什么声音先行”，才算可复用。

## 15. 导演调度：镜头运动之前，先设计人物和空间怎么动

很多 AI 分镜的问题不是运镜少，而是没有调度。调度要先解决“人、物、空间、视线、声音”的关系。

### 15.1 人物调度

- 谁在主动逼近，谁在后退。
- 谁占据画面中心，谁被挤到边缘。
- 谁被前景遮挡，谁被光线隔离。
- 谁的视线引导下一镜。
- 谁的动作触发镜头运动。

可写法：

```text
陆沉从人群反方向挤入，身体始终逆着围观人潮移动；前景乘客肩膀不断擦过镜头，形成拥堵和压迫。
```

### 15.2 空间调度

空间不是背景，要服务冲突：

- 门口 = 出入、阻隔、逃离、危险入口。
- 走廊 = 压迫、追逐、无处可躲。
- 电梯/车厢 = 封闭、失控、群体困局。
- 桌子/柜台 = 权力边界、谈判距离。
- 窗户/屏幕 = 画内信息源、外部威胁入口。

可写法：

```text
车厢门大敞但无人敢进，门框像一道明亮边界，把站台的混乱和车厢内的死寂切成两层空间。
```

### 15.3 视线调度

视线是最便宜也最稳定的剪辑胶水：

- 角色看向画外 → 下一镜给被看的对象。
- 角色突然回头 → 下一镜给威胁或反应。
- 多人同时看同一点 → 下一镜给线索或异常。
- 角色不敢看 → 镜头可以反向给他的手、脚、喉结。

可写法：

```text
大爷说到“美女图”时不敢直视陆沉，眼神飘向车厢深处；下一镜顺着他的视线切到电子屏上的打码照片。
```

## 16. 运镜动机库：每种运动都要有叙事理由

### 16.1 固定镜头

适合：

- 让表演、对白、空间关系自己产生张力。
- 表现凝固、失控前的安静、异常静止。
- 给观众时间观察细节。

错误用法：把所有镜头都写成固定，画面会像图集，不像视频。

AI 写法：

```text
固定镜头不移动，乘客僵硬站立的细微呼吸与手机屏闪烁成为唯一动态，强化诡异静止感。
```

### 16.2 慢推

适合：

- 情绪加压。
- 角色意识到真相。
- 观众被迫靠近危险信息。

AI 写法：

```text
镜头从中近景缓慢推向陆沉的眼睛，背景人声逐渐压低，突出他锁定异常线索的瞬间。
```

### 16.3 拉远

适合：

- 展示角色孤立。
- 揭示更大空间或更严重局面。
- 情绪从个人扩展到环境。

AI 写法：

```text
镜头从外卖小哥崩溃的近景缓缓拉远，露出整节车厢里一动不动的乘客，个人焦虑扩展成群体异常。
```

### 16.4 横摇

适合：

- 跟随视线发现新信息。
- 从一个人物转到另一个人物。
- 展示空间连贯关系。

AI 写法：

```text
镜头顺着工作人员挥手的方向横摇，掠过举手机的人群，最终停在大敞的车厢门口。
```

### 16.5 横移 / 跟拍

适合：

- 人物移动。
- 展示并行空间。
- 让前景产生速度和层次。

AI 写法：

```text
镜头贴着陆沉侧后方横移跟拍，前景围观者的手臂和手机不断掠过镜头，制造拥挤视差。
```

### 16.6 环绕

适合：

- 关系变化。
- 心理旋涡。
- 被围观、被审判、被包围。

AI 写法：

```text
镜头以陆沉为中心半环绕，围观人群和闪烁手机屏在背景形成旋转压迫，突出他被信息包围。
```

### 16.7 升降 / 摇臂

适合：

- 从人物升到环境，表现规模。
- 从环境降到人物，表现命运压下。
- 展示高低权力关系。

AI 写法：

```text
镜头从电子屏特写缓慢升高，俯视整个站台人群都被同一张照片吸引，异常范围被完整揭示。
```

### 16.8 手持微晃

适合：

- 现场感、慌乱、不稳定、新闻感。
- 人群拥挤、追逐、冲突爆发。

AI 写法：

```text
手持微晃镜头在人群缝隙中穿行，画面偶尔被手机和肩膀遮挡，强化站台混乱的临场感。
```

### 16.9 变焦 / 滑动变焦

变焦改变画面大小但不改变透视；推轨改变透视和空间关系。滑动变焦适合表现眩晕、恐惧、认知崩塌，但不要滥用。

AI 写法：

```text
镜头保持陆沉面部大小不变，同时背景车厢被滑动变焦拉伸变远，表现他意识到异常范围超出预期。
```

## 17. 剪辑思维：每个镜头都要为下一镜留下钩子

### 17.1 动作接动作

用上一镜动作的方向接下一镜：

```text
上一镜：大爷颤抖的手指向车厢。
下一镜：顺着手指方向切入车厢深处的手机屏光。
```

### 17.2 视线接视线

```text
上一镜：陆沉抬眼看向电子屏。
下一镜：电子屏特写，热搜标题占满画面。
```

### 17.3 声音先行

```text
上一镜画面还停在僵硬乘客脸上，工作人员“别拍”的喇叭声先入。
下一镜切到工作人员举着喇叭冲人群喊。
```

### 17.4 反应后置

先给信息，再给人物反应；或先给反应，再揭示信息。选择取决于悬念：

- 先信息后反应：观众和角色同步理解。
- 先反应后信息：观众先被吊起疑问。

### 17.5 图形匹配

用形状、颜色、方向接镜：

```text
碎屏手机的裂纹切到地铁玻璃门上的裂状反光，形成视觉连贯。
```

## 18. AI 视频分镜专用：把“主体运动”和“摄影机运动”分开写

AI 视频提示词最怕把动作混成一句，例如“镜头追着他冲过去”。应拆成两层：

```text
主体运动：陆沉从人群中逆向挤入，右手护住工具包，肩膀连续撞开围观者。
摄影机运动：镜头在他左后方低位跟拍，保持中景，前景手机屏幕快速掠过形成视差。
```

推荐字段顺序：

```text
主体是谁 → 主体做什么 → 表情/肢体细节 → 空间关系 → 摄影机如何动 → 光影如何变 → 声音如何接
```

对 AI 更友好的动作表达：

- 不写：“气氛压抑。”
- 改写：“站台冷白灯闪烁，乘客手机屏同时亮起，人物脸上出现断续的蓝白反光。”

- 不写：“镜头很有压迫感。”
- 改写：“低机位贴近陆沉胸口向上拍，前景人群肩膀遮挡画面两侧，背景车厢门像黑色矩形压在他身后。”

- 不写：“角色很害怕。”
- 改写：“大爷嘴唇发抖，吞咽动作明显，抓住陆沉袖子的手指骨节发白，眼神避开车厢深处。”

## 20. 常见失败输出与修正

### 20.1 只有术语，没有动机

失败：

```text
中景，推镜，冷色调，紧张氛围。
```

修正：

```text
中景慢推，镜头从陆沉胸前工具包推向他的眼睛；他听到“美女图”三个字后眼神突然收紧，背景人群声被压低，推动悬念升级。
```

### 20.2 只有人物动作，没有摄影机动作

失败：

```text
陆沉走进站台，人群很乱。
```

修正：

```text
陆沉逆着人流挤进站台，右手护住黑色工具包；镜头在他侧后方横移跟拍，前景手机屏和肩膀不断遮挡，强化拥堵现场感。
```

### 20.3 摄影机运动和主体运动打架

失败：

```text
角色静止不动，镜头快速跟拍。
```

修正：

```text
角色静止不动时用慢推或固定；角色移动时再用跟拍、横移或手持穿行。
```

### 20.4 一镜塞太多剧情

失败：

```text
大爷抓住陆沉说明老伴看到美女图后卡住，陆沉看电子屏发现热搜并冲进车厢。
```

修正：

```text
拆成三镜：大爷抓袖求助；陆沉顺着视线看电子屏；陆沉做出进入车厢的决定。
```

## 21. 面向剧本转分镜的强约束建议

如果要把本附件接入剧本转分镜提示词，建议只作为辅助规范，并附加以下硬约束：

```text
1. 每条 _::~RECORD::~_ 只能输出一个镜头，不能在同一条记录里写多个【镜头NN】。
2. 镜头编号全局递增，禁止每条记录从【镜头01】重启。
3. 原文所有对白必须逐字保留；可增加动作、表情、镜头和声音设计，但不能删减对白。
4. 运镜必须服务情节，不得为了炫技加入无动机运动。
5. 每个镜头必须分清主体运动和摄影机运动。
6. 每个镜头必须留下至少一种衔接点：动作、视线、声音、构图、道具或情绪。
```

## 22. 剪辑心理：库里肖夫效应在 AI 分镜里的用法

观众会把相邻镜头自动组合成意义。同一张“无表情的脸”，接在不同画面后，观众会读出不同情绪。因此，AI 分镜不要只写单镜头，还要设计“上一镜给什么，下一镜观众如何理解”。

### 22.1 反应镜头不是补空镜，而是制造意义

用法：

- 先给异常物，再给角色反应：观众确认角色也看到了异常。
- 先给角色反应，再给异常物：观众先产生疑问，再获得答案。
- 先给人群反应，再给主角动作：放大事件规模。

可写法：

```text
上一镜：电子屏上“看一眼就忘不了”的标题闪烁。
下一镜：陆沉没有立刻说话，只是瞳孔微缩，手指慢慢按住工具包拉链。
观众理解：这条热搜不是普通八卦，而是异常线索。
```

### 22.2 情绪不要靠形容词，要靠前后镜头赋义

失败：

```text
陆沉感到震惊。
```

修正：

```text
先给电子屏上打码照片的白亮下半张脸，再切陆沉近景；他眼神短暂停滞，呼吸停半拍，随后手指压住工具包锁扣。
```

### 22.3 适合悬疑/怪谈/惊悚的三段式

```text
线索特写 → 人物反应 → 空间揭示
```

示例：

```text
碎屏手机停在同一张照片 → 外卖小哥眼眶发红崩溃求助 → 拉远看到整节车厢的人都僵在手机前。
```

## 23. 连续性剪辑：让镜头看起来“自然接上”

### 23.1 视线匹配

角色看向画外，下一镜给他看到的对象。这个方法特别适合线索揭示。

```text
镜头A：陆沉抬眼看向站台上方，眼神锁定电子屏。
镜头B：电子屏特写，热搜标题和打码照片占满画面。
```

写给 AI 时必须明确：

- 谁在看。
- 看向画面哪个方向。
- 下一镜出现什么。

### 23.2 动作匹配

上一镜动作开始，下一镜动作完成，让剪辑点藏在动作中。

```text
镜头A：大爷颤抖的手伸向陆沉袖口。
镜头B：近景切到手指死死攥住布料，骨节发白。
```

AI 写法：

```text
承接上一镜伸手动作，切到手部特写，动作在剪辑点后完成，形成连续感。
```

### 23.3 图形匹配

用相似形状、颜色、运动方向接镜，适合做转场或隐喻。

```text
碎屏手机的裂纹 → 地铁门玻璃上的裂状反光。
```

### 23.4 声音桥

声音可以先于画面出现，或者跨镜延续，让剪辑更顺。

```text
工作人员的喇叭声先在车厢静止画面上响起，下一镜才切到他举着喇叭冲人群喊。
```

## 24. 长镜头和一镜到底：什么时候值得用

长镜头的重点不是“镜头很长”，而是让空间、动作、人物关系在同一时间里连续发生。

适合：

- 人物穿过复杂空间。
- 观众需要实时感受压力。
- 多个信息点沿路线依次出现。
- 角色状态在不中断的表演中变化。

不适合：

- 只是为了炫技。
- 动作和信息太多导致 AI 一镜生成不清。
- 对白太长但没有空间变化。

AI 可执行写法：

```text
连续跟拍长镜头，镜头从陆沉背后低位进入站台，先掠过举手机的人群，再跟随他侧身挤过闸机，最后停在车厢门口的大爷脸上；整个镜头不切，靠前景遮挡和人物走位完成空间转换。
```

长镜头拆解公式：

```text
起点画面 → 行进路线 → 中途信息点 → 人物状态变化 → 终点落点
```

如果 AI 生成不稳定，应拆成 3-5 个普通镜头，并保持动作接点：

```text
跟拍进入 → 前景遮挡切换 → 线索特写 → 人物反应 → 落到新空间
```

## 25. 滑动变焦：只给“认知崩塌”或“空间异变”

滑动变焦的视觉逻辑是：主体在画面中大小基本不变，背景透视被拉伸或压缩，观众产生空间不稳定感。它适合少量用于关键心理瞬间。

适合：

- 角色突然意识到危险。
- 看似正常的空间变得不可信。
- 现实感被打破。

不适合：

- 普通对话。
- 每次惊讶都用。
- AI 视频无法稳定表现时强行使用。

AI 写法：

```text
滑动变焦：陆沉面部大小保持不变，背景车厢门和僵立乘客被透视拉远，空间像突然变深，表现他意识到异常范围超出预期。
```

简化替代写法：

```text
慢推到陆沉眼睛，同时背景逐渐虚化变暗，用低频音效替代复杂滑动变焦。
```

## 26. AI 运镜可控参数：把抽象运镜改写成参数化描述

AI 视频控制相关研究强调：摄影机轨迹、主体运动、焦距/视场、镜头内参和外参最好分开描述。对提示词而言，不需要写数学参数，但要把运动拆清楚。

### 26.1 推荐拆分

```text
主体运动：谁，从哪里到哪里，速度如何，动作细节是什么。
摄影机位置：正面/侧后/低位/高位/越肩/主观视角。
摄影机运动：推、拉、横移、环绕、升降、固定、手持微晃。
运动速度：缓慢、平稳、急促、突然停住。
焦距/景深：广角空间压迫、长焦压缩、浅景深隔离主体、深焦保留环境线索。
构图目标：主体保持居中、主体从边缘进入、前景遮挡、负空间。
结束落点：停在人物表情、道具、门口、屏幕文字或反应。
```

### 26.2 可控句式

```text
镜头在[位置]以[速度]进行[运动]，始终保持[主体]处于[构图位置]；前景[遮挡/掠过]，背景[变化]，最后停在[落点]。
```

示例：

```text
镜头在陆沉左后方以平稳速度横移跟拍，始终保持陆沉位于画面右三分之一；前景乘客手机屏不断掠过，背景车厢门逐渐靠近，最后停在门口大爷抓住袖子的手上。
```

### 26.3 避免 AI 混乱的写法

不要写：

```text
镜头快速旋转、推拉、跟拍、升降，气氛紧张。
```

改写：

```text
只使用一种主运镜：手持低位跟拍。镜头从陆沉背后进入人群，轻微晃动，前景遮挡频繁，最后停在车厢门口。
```

## 27. 类型片运镜套路：按题材选择，而不是固定套用

### 27.1 悬疑 / 规则怪谈

常用：

- 局部特写先于全景。
- 慢推、固定、低频音效。
- 负空间和遮挡。
- 视线匹配揭示线索。

示例：

```text
先给碎屏手机上的同一张照片，再给乘客僵硬的眼睛，最后拉远露出整节车厢，形成“局部异常扩展为群体异常”的递进。
```

### 27.2 爽剧 / 强冲突

常用：

- 正反打对话。
- 急推、低机位、反应镜头。
- 道具特写作为反转证据。
- 声音桥强化打脸节奏。

示例：

```text
反派质问时用低角度中近景压迫主角；主角亮出证据时切手机特写，再切反派表情崩塌。
```

### 27.3 现实 / 纪实

常用：

- 平视机位。
- 手持微晃但不过度。
- 长焦压缩人群。
- 环境声和沉默保留。

示例：

```text
平视手持跟拍角色穿过拥挤站台，不刻意美化灯光，让广播声、脚步声和人群噪声形成真实现场。
```

### 27.4 喜剧

常用：

- 固定镜头让荒诞动作自己发生。
- 反应镜头延迟半拍。
- 远景保留人物尴尬走位。
- 突然切特写强化包袱。

示例：

```text
角色说完离谱台词后不立刻切走，固定中景多停半秒，让旁边人缓慢转头的反应形成笑点。
```

## 28. 面向“整页分镜/单页画面”的导演设计

当一个分镜是一整页或整幅画面时，不能按普通单镜头只写一个动作点，而要像设计漫画页或一张复杂剧照：

必须写清：

- 页面/画布尺寸由用户选择。
- 主视觉中心在哪里。
- 视线阅读顺序从哪里到哪里。
- 前景、中景、背景各承载什么剧情。
- 对白气泡/屏幕文字不能遮挡关键动作。
- 一整页内可以包含多个动作层，但不能遗漏对白。

AI 写法：

```text
整页画面，按用户选择的画布尺寸构图。主视觉中心是车厢门口蹲着的外卖小哥；前景右侧是碎屏手机特写，中景是小哥崩溃抬头求助，背景深处是一整节僵立乘客和冷白车厢灯。阅读顺序从手机订单界面开始，移动到小哥台词，再被车厢深处异常人群吸引。所有对白完整保留，文字区域避开人物表情和手机屏幕。
```

整页画面检查：

```text
主动作是否清楚？
对白是否完整？
读者第一眼看哪里？
第二眼看哪里？
关键线索是否被挡住？
画布比例是否跟用户选择一致？
```

## 29. 180 度轴线、30 度规则和正反打：让对话不乱

### 29.1 180 度轴线

两个人对话时，先在他们之间建立一条虚拟轴线。摄影机应保持在轴线同一侧，这样观众才能稳定理解谁在左、谁在右、谁看向谁。

AI 分镜写法：

```text
保持站台门口对话轴线统一：陆沉位于画面右侧看向左，大爷位于画面左侧看向右，正反打镜头不越轴。
```

适用场景：

- 双人对话。
- 审问、争吵、谈判。
- 主角和威胁源对峙。
- 人物隔着桌子、门、车厢口交流。

### 29.2 30 度规则

连续切同一人物或同一对象时，角度或景别变化要足够明显，否则像跳切。可以通过以下方式避免：

- 景别从中景切近景。
- 机位至少有明显角度变化。
- 借动作、前景遮挡、视线或声音完成过渡。

AI 分镜写法：

```text
从陆沉中景切到脸部近景，机位由斜侧45度改为正面近景，避免同角度轻微跳切。
```

### 29.3 三镜头法

经典对话拆法：

```text
建立镜头：交代两人位置和空间。
正打镜头：人物A说话。
反打镜头：人物B反应或回应。
```

短剧/漫画分镜可用模板：

```text
镜头1：车厢门口全景，陆沉、大爷、围观人群位置清楚。
镜头2：大爷中近景抓住陆沉袖子，说完整求助对白。
镜头3：陆沉反应近景，眼神变化后看向车厢深处。
```

注意：

- 不要为了省镜头把一长段对话塞进一个镜头。
- 长对白应拆成连续正反打，但对白本身不能删。
- 每个正反打都要有明确表情和动作变化，不要只换说话人。

## 30. 构图规则：用画面位置讲关系

### 30.1 三分法

主体放在三分线或交点上，画面更有张力；移动人物前方应留出“行动空间”。

AI 写法：

```text
陆沉位于画面右三分之一，左侧留出车厢门和围观人群的负空间，让观众感到他正被异常空间吸引。
```

### 30.2 中心构图

适合仪式感、压迫、对称、异常、强控制。

AI 写法：

```text
车厢门被放在画面正中央，门内乘客整齐僵立，形成对称而不自然的压迫感。
```

### 30.3 负空间

让主体旁边留出大块空白或黑暗，用来暗示孤立、威胁、未知。

AI 写法：

```text
外卖小哥蹲在画面下方角落，身后大面积冷白车厢空出，僵立乘客被压在深处，突出他的无助。
```

### 30.4 前景遮挡

前景可以制造偷窥感、拥挤感、压迫感，也能帮剪辑转场。

AI 写法：

```text
前景乘客举起的手机半遮挡镜头，陆沉从手机缝隙中穿过，画面带有被人群围困的现场感。
```

### 30.5 深度层次

至少把画面分成前景、中景、背景：

```text
前景：碎屏手机和发抖手指。
中景：崩溃的外卖小哥。
背景：车厢内僵立乘客和冷白灯。
```

这样 AI 更容易生成有空间纵深的画面，而不是平面角色图。

## 31. 焦距和景深：不要只写景别，也要写空间压缩关系

### 31.1 广角

效果：

- 空间更夸张。
- 前景更大，背景更远。
- 适合狭窄空间、压迫、临场感。

AI 写法：

```text
广角低机位靠近碎屏手机，手机裂纹在前景被夸大，车厢深处僵立人群被拉远，空间显得异常狭长。
```

### 31.2 长焦

效果：

- 压缩空间距离。
- 人群显得拥挤。
- 背景更贴近主体。

AI 写法：

```text
长焦压缩站台人群，陆沉被举手机的乘客层层挤压在画面中，背景车厢门似乎贴近他的后背。
```

### 31.3 浅景深

效果：

- 隔离主体。
- 强调心理或关键道具。
- 隐藏背景信息。

AI 写法：

```text
浅景深聚焦大爷抓住袖子的手，背景陆沉面部虚化，只保留他低头看手的轮廓。
```

### 31.4 深焦

效果：

- 前中后景信息同时清楚。
- 适合复杂调度、线索共存、群像压力。

AI 写法：

```text
深焦构图同时保留前景碎屏手机、中景外卖小哥、背景僵立乘客，让观众一次读到三层异常。
```

## 32. 声音导演思维：声音不是附属，它能提前引导镜头

### 32.1 画外声

画外声可以制造空间和悬念，但不能替代剧情画面。

```text
车厢画面保持死寂，画外先传来工作人员失真的喇叭声：“别拍！把手机放下！”随后切到站台人群。
```

### 32.2 环境声

环境声要有场景特异性：

- 地铁：低频嗡鸣、广播混响、刹车摩擦、闸机滴声。
- 医院：监护仪滴声、走廊回音、轮床滚动。
- 办公室：键盘声、空调低噪、玻璃门开合。
- 雨夜：雨点击打、轮胎压水、远处雷声。

AI 写法：

```text
地铁低频嗡鸣持续压底，手机电量警告音间隔响起，和外卖小哥急促呼吸形成节奏反差。
```

### 32.3 声音转场

```text
手机提示音在上一镜响起，下一镜切到碎屏手机特写；声音成为剪辑钩子。
```

### 32.4 声音反差

画面很乱但声音突然抽空，或画面静止但声音刺耳，都能强化异常。

```text
围观人群画面仍在晃动，但环境声短暂抽离，只剩电子屏滚动时的细小电流声。
```

## 33. 动画/漫画 layout 思路：把一镜拆成可画、可动、可读

动画 layout 会提前规划背景、角色比例、透视、光影和安全框。对 AI 漫画/视频同样适用。

每个镜头要同时回答：

- 背景层需要多大？
- 角色在背景中的比例是多少？
- 前景有没有遮挡层？
- 角色动作方向是否符合透视？
- 光源从哪里来？
- 对白和字幕放哪里不遮挡表情？

AI 写法：

```text
背景层为地铁车厢纵深透视，前景右侧放大碎屏手机，中景外卖小哥蹲在门口，背景乘客沿车厢纵深排列；顶部冷白灯作为主光源，手机屏幕提供局部蓝白补光。
```

### 33.1 安全框和文字避让

整页漫画或分镜图中，文字不能遮挡：

- 眼睛。
- 嘴部表情。
- 关键手部动作。
- 手机/屏幕文字。
- 门口、凶器、线索道具等剧情关键物。

可写入提示词：

```text
对白文字区域避开人物眼睛、嘴部表情和碎屏手机界面，保留关键线索清晰可读。
```

## 34. 短剧高转化镜头节奏

短剧和信息流视频通常需要更快的情绪节奏，但快不等于乱。

### 34.1 开头 3 镜

```text
异常钩子 → 人物困境 → 规则/危险线索
```

示例：

```text
1. 碎屏手机特写，订单界面和怪异照片同时出现。
2. 外卖小哥崩溃求助，完整说出确认收货对白。
3. 拉远揭示整节车厢乘客僵立，异常升级。
```

### 34.2 每 3-5 镜给一次信息推进

推进可以是：

- 新角色出现。
- 新线索出现。
- 关系反转。
- 空间范围扩大。
- 危险规则被说明。

### 34.3 爽点和悬念不能混在同一镜

一镜只做一个主要情绪落点：

- 悬念镜：隐藏答案。
- 反转镜：揭示答案。
- 爽点镜：展示压制或反击。
- 情绪镜：给角色表情和停顿。

## 35. AI 分镜质量自检清单

输出前逐条检查：

```text
1. 每条记录是否只有一个【镜头NN】？
2. 镜头编号是否全局递增？
3. 原文所有对白是否逐字保留？
4. 每个镜头是否写清主体运动和摄影机运动？
5. 每个镜头是否有明确导演目的？
6. 上下镜是否至少有一个衔接点？
7. 人物位置和视线方向是否符合轴线？
8. 景别变化是否足够明显，避免轻微跳切？
9. 画面是否有前景/中景/背景层次？
10. 光源、声音、道具是否服务剧情？
11. 是否存在无动机炫技运镜？
12. 是否把参考资料误写进剧情？
13. 整页画面是否按用户尺寸，并保证对白不遮挡关键动作？
```

## 36. 推荐给剧本转分镜的最终辅助提示词片段

可追加到主提示词或作为 `screenplay_reference` 参数输入：

```text
请以导演拉片思维转分镜。每个镜头先判断叙事目的，再选择景别、机位、构图、调度、运镜和声音。不要只堆术语。

硬性要求：
1. 每条 _::~RECORD::~_ 只写一个镜头，记录内只能出现一个【镜头NN】。
2. 镜头编号全局递增。
3. 原文所有对白、屏幕文字、人物说出口的句子必须逐字完整保留。
4. 每个镜头必须写清主体运动和摄影机运动。
5. 运镜必须有动机：跟随主体、揭示信息、加压情绪、衔接视线、展示空间或制造悬念。
6. 每个镜头至少保留一种衔接钩子：动作、视线、声音、构图、道具或情绪。
7. 对话场景遵守轴线和正反打逻辑；长对白拆连续镜头，但对白不删。
8. 如果是整页分镜，按用户选择的画布尺寸组织前景/中景/背景和阅读顺序，完整保留对白。
```

## 37. 经典拉片方法抽象：把案例变成可复用规则

以下不是要求模仿具体电影，而是抽象公开影视分析中常见的导演方法，转成 AI 分镜可用的规则。

### 37.1 黑泽明式“运动接运动”

核心思路：

- 画面里尽量有清楚的运动方向。
- 剪辑点藏在动作中。
- 镜头运动、人物运动、环境运动、剪辑运动共同形成节奏。

适合：

- 人群混乱。
- 动作冲突。
- 主角穿过复杂空间。
- 情绪从压抑转向爆发。

AI 写法：

```text
上一镜大爷伸手抓向陆沉袖口，下一镜切到手部特写，抓住动作在剪辑点后完成；镜头借动作切换隐藏剪辑，让求助动作更急迫。
```

可复用规则：

```text
只要人物有“伸手、转头、起身、推门、回头、夺物、摔落”等动作，就优先考虑动作匹配剪辑。
```

### 37.2 多机位动作：同一动作从不同角度捕捉

核心思路：

- 大动作很难重复，正式拍摄常用多机位捕捉不同角度。
- AI 分镜可以把同一事件拆成多个角度，但每条记录仍只写一个镜头。

适合：

- 打斗、摔倒、冲撞、追逐。
- 人群混乱。
- 角色突然进入危险空间。

AI 写法：

```text
镜头A：全景看陆沉从人群中挤向车厢门，交代路线。
镜头B：低位近景看他的肩膀撞开围观者，强调阻力。
镜头C：车厢门内反拍，陆沉踏入门框，背景乘客僵立。
```

注意：

- 不是一条记录里写三个镜头。
- 每个镜头只承担一个角度和一个叙事目的。

### 37.3 长焦压缩人群

核心思路：

- 长焦会压缩空间，让背景像贴近主体。
- 人群、车辆、建筑会显得更密、更压迫。

适合：

- 围观、拥堵、追捕、审判感。
- 主角被人群包围。
- 背景危险逼近。

AI 写法：

```text
长焦中景压缩站台人群，陆沉被层层举起的手机屏挤在画面中央，背景车厢门像贴在他身后，空间压迫感增强。
```

### 37.4 纪录片式跟拍

核心思路：

- 镜头像现场人员跟着事件移动。
- 不是完美稳定，而是有轻微找焦、遮挡、跟丢和重新捕捉。

适合：

- 突发事故。
- 新闻现场。
- 规则怪谈中的现实质感。

AI 写法：

```text
手持跟拍从人群后方挤入，画面被肩膀和手机短暂遮挡，镜头轻微寻找焦点后重新锁定陆沉，营造真实突发现场。
```

### 37.5 先遮挡后揭示

核心思路：

- 先不让观众看全貌。
- 通过门缝、玻璃反光、前景人群、屏幕边缘逐步释放信息。

适合：

- 悬疑、惊悚、异常发现。
- 怪物/危险/真相首次出现。
- 不想一开始就把画面说透。

AI 写法：

```text
前景车门边框遮住车厢大半，只露出几只握着手机的僵硬手；镜头缓慢横移，才逐渐露出整排僵立乘客。
```

## 38. 分镜节奏模型：按信息释放组织镜头

### 38.1 三层递进

```text
局部异常 → 人物反应 → 空间全貌
```

适合开场钩子。

示例：

```text
碎屏手机特写 → 外卖小哥崩溃对白 → 拉远露出整节车厢异常。
```

### 38.2 问题-证据-反应

适合推理和反转：

```text
人物提出疑问 → 道具或屏幕给证据 → 人物反应确认信息重量
```

示例：

```text
大爷说老伴看见美女图后卡住 → 电子屏热搜照片特写 → 陆沉眼神收紧。
```

### 38.3 压迫-停顿-爆发

适合冲突戏：

```text
反派逼近 → 主角沉默停顿 → 证据/动作/对白反击
```

每段要分镜，不要塞一镜。

### 38.4 平静-异常-失控

适合怪谈/事故：

```text
正常环境声和普通行为 → 一个细节不对 → 群体或空间失控
```

示例：

```text
正常地铁广播 → 乘客都盯同一张图不动 → 站台人群举手机围观、工作人员失控喊话。
```

## 39. 运动层级：画面至少要有一种运动，最好不超过三种

电影画面中的运动可以分层：

| 运动层 | 例子 | 用途 |
|---|---|---|
| 人物运动 | 走、跑、回头、伸手、后退 | 推进行动和情绪 |
| 摄影机运动 | 推、拉、摇、移、跟、升降 | 改变信息和情绪 |
| 环境运动 | 灯闪、雨落、人群流动、门开合 | 增加现场感 |
| 光影运动 | 屏幕闪烁、车灯掠过、阴影移动 | 暗示危险或节奏 |
| 焦点运动 | 前景转焦到背景 | 引导观众看线索 |
| 剪辑运动 | 动作匹配、声音桥、图形匹配 | 连接上下镜 |

AI 分镜建议：

```text
每个镜头选择 1 个主运动 + 1 个辅助运动。不要在同一镜同时写推拉摇移跟环绕升降。
```

示例：

```text
主运动：陆沉横向挤过人群。
辅助运动：前景手机屏掠过镜头。
摄影机：侧后方平稳跟拍。
```

## 40. AI 视频限制反推分镜写法

当前多数 AI 视频模型仍容易出现：

- 长片段叙事漂移。
- 复杂动作变形。
- 多人互动错位。
- 文本和屏幕字不稳定。
- 镜头运动和主体运动混淆。
- 角色连续性不稳。

因此分镜要反向适配：

### 40.1 短镜头优先

把复杂动作拆成 3-6 秒短镜：

```text
伸手 → 抓住 → 反应 → 看向线索
```

### 40.2 单镜只做一个核心动作

失败：

```text
陆沉挤进人群、听完大爷解释、看电子屏、决定进车厢。
```

修正：

```text
镜头1：陆沉挤进人群。
镜头2：大爷抓袖求助并说完整对白。
镜头3：陆沉看向电子屏。
镜头4：陆沉按住工具包，决定进入车厢。
```

### 40.3 屏幕文字单独给特写

如果有关键文字，不要埋在复杂画面里：

```text
电子屏特写，画面只保留热搜标题、打码配图和滚动光效，确保“地铁神颜路透”“看一眼就忘不了”清晰可读。
```

### 40.4 多人场景要明确谁是主角

```text
围观人群只作为背景动态，主焦点始终锁定陆沉和大爷，不让 AI 平均刻画所有人。
```

## 41. 可直接复制的“导演式分镜描述模板”

```text
【镜头目的】：交代空间 / 推进行动 / 表达情绪 / 揭示线索 / 强化冲突 / 制造悬念 / 完成衔接
【主体运动】：谁做什么，动作起点和终点是什么
【摄影机运动】：机位、景别、运镜、速度、结束落点
【调度关系】：人物与人物、人物与道具、人物与空间的相对位置
【构图层次】：前景、中景、背景分别放什么
【信息释放】：观众此刻看到什么，角色是否也看到
【声音设计】：对白、环境声、音效、声音桥
【剪辑接点】：上一镜如何接入，下一镜如何接出
```

把它压缩成正式分镜字段时，不输出这些标题，只把信息融入“动作细节、镜头类型&景别&运镜、光影氛围、音效、画面、声音”。

## 43. 中文提示词术语规范：同一个意思用稳定词

为了让 AI 输出稳定，中文分镜提示词里尽量固定使用以下术语，不要同一概念反复换说法。

| 概念 | 推荐写法 | 避免写法 |
|---|---|---|
| 画面中人物和空间安排 | 场面调度 | 镜头安排、画面安排、摆位混用 |
| 双人对话切换 | 正反打 | 对切、互拍、来回拍混用 |
| 先交代空间再切双方 | 三镜头法 | 三段镜头、三步镜头混用 |
| 动作/图形/色彩接镜 | 匹配剪辑 | 顺滑转场、自然衔接笼统表达 |
| 长时间不中断拍摄 | 长镜头 / 一镜到底 | 长焦镜头误用 |
| 角色看向某处再切对象 | 视线匹配 | 看过去、顺眼神带过去笼统表达 |
| 上一镜动作接下一镜动作 | 动作匹配 | 动作连接、动作衔接混用 |
| 先听到声音再切画面 | 声音桥 / 声音先行 | 声音转场笼统表达 |

中文 AI 分镜推荐句式：

```text
采用正反打对话镜头，保持 180 度轴线统一；上一镜大爷看向车厢深处，下一镜用视线匹配切到车厢门内的手机屏光。
```

## 44. 场面调度四件套：位置、走位、视线、遮挡

场面调度不是“镜头运动”的同义词，而是镜头前的一切如何被组织。每个镜头先写调度，再写运镜。

### 44.1 位置

人物和道具在画面里的相对位置决定关系：

```text
陆沉站在车厢门外，半只脚越过门线；大爷在画面左侧抓住他袖子，车厢深处僵立乘客位于背景中央。
```

### 44.2 走位

走位体现主动和被动：

```text
陆沉主动向车厢门内迈步，大爷被他带得向前踉跄半步，围观人群下意识后退让出狭窄通道。
```

### 44.3 视线

视线决定下一镜切什么：

```text
陆沉听到“美女图”后没有看大爷，而是越过他的肩膀看向电子屏；下一镜切电子屏特写。
```

### 44.4 遮挡

遮挡既能制造空间层次，也能隐藏信息：

```text
前景一部正在拍摄的手机遮住车厢左半边，镜头横移时才露出僵立乘客的手和屏幕。
```

场面调度检查：

```text
人物站哪？
从哪走到哪？
看向哪里？
谁挡住谁？
遮挡是为了隐藏信息、制造拥挤，还是做转场？
```

## 45. 匹配剪辑可用模板

### 45.1 动作匹配

```text
上一镜：角色抬手按向门把手。
下一镜：门把手特写，手指压下去，动作完成。
```

### 45.2 视线匹配

```text
上一镜：角色突然看向画面右上方。
下一镜：画面右上方的电子屏特写。
```

### 45.3 图形匹配

```text
上一镜：手机屏幕裂纹呈放射状。
下一镜：地铁顶灯反光在玻璃门上形成相似裂状线条。
```

### 45.4 色彩匹配

```text
上一镜：手机蓝白光照亮角色手指。
下一镜：电子屏蓝白光占满画面，色彩延续。
```

### 45.5 声音匹配

```text
上一镜：手机低电量提示音响起。
下一镜：切到碎屏手机特写，提示音来源被揭示。
```

AI 分镜提示：

```text
每次转场至少选择一种匹配关系，不要只写“自然切换”。
```

## 46. 长镜头的拆分版：AI 不稳时这样降级

如果提示词要求“一镜到底”，AI 容易出现动作变形或叙事漂移。可以把长镜头意图拆成连续短镜，但保留同一空间路线。

原始长镜头意图：

```text
陆沉从闸机口穿过人群走到车厢门口，途中看到工作人员、围观手机、大爷求助和电子屏线索。
```

降级拆分：

```text
镜头1：闸机口中景，陆沉逆人流进入。
镜头2：侧后方跟拍，前景手机屏频繁遮挡。
镜头3：工作人员喇叭声先行，切到他阻止人群拍摄。
镜头4：大爷冲入画面抓住陆沉袖子，完整说出求助对白。
镜头5：陆沉视线匹配切电子屏，热搜和打码图特写。
```

这样既保留长镜头的空间路线，又适配 AI 视频生成的短镜稳定性。

## 47. 拉片复盘输出格式：让 AI 学“规律”而不是背“案例”

每次拉片后，把案例复盘成规则：

```text
原片段手法：
导演为什么这样做：
如果换成普通镜头会损失什么：
适合复用的剧情类型：
可迁移到本项目的提示词：
禁止滥用的情况：
```

示例：

```text
原片段手法：先给局部道具，再给人物反应，最后拉开空间。
导演为什么这样做：让观众先产生疑问，再确认角色也意识到异常，最后理解事件规模。
适合复用：悬疑、规则怪谈、事故开场、线索揭示。
提示词：局部线索特写 → 人物反应近景 → 空间全貌拉远。
禁止滥用：普通生活戏、无需悬念的说明性段落。
```

## 48. 负面清单：最容易把分镜写废的表达

以下表达尽量少用，或者必须补足具体镜头和调度信息：

- “氛围感拉满”
- “很有电影感”
- “镜头很高级”
- “情绪到位”
- “运镜丰富”
- “画面震撼”
- “冲击力很强”
- “层次丰富”
- “自然衔接”

这些词不是不能写，而是不能单独写。它们后面必须跟具体信息：

```text
不是：镜头很有压迫感。
而是：低机位推近，大爷抓住袖子的手占满前景，背景车厢门和僵立乘客形成压迫。
```

```text
不是：很有电影感。
而是：冷白顶光、浅景深、前景遮挡、慢推、声音先行，形成悬疑电影式节奏。
```

```text
不是：情绪很强。
而是：人物先沉默半拍，再用眼神、手指和呼吸完成情绪推进。
```

## 49. 可直接复制的最终提示词模板

### 49.1 通用导演式分镜模板

```text
请以导演拉片思维完成分镜。先判断每个镜头的叙事目的，再决定景别、机位、构图、调度、运镜和声音。

硬性要求：
1. 每条记录只能包含一个镜头，禁止在同一条记录里写多个【镜头NN】。
2. 镜头编号全局递增，不能重置。
3. 原文所有对白、人物说出口的句子、屏幕文字必须逐字完整保留。
4. 情节优先，动作优先，不能省略关键事件和转折。
5. 每个镜头必须同时写清主体运动和摄影机运动。
6. 运镜必须有叙事动机，不能为了炫技乱用推拉摇移跟升降。
7. 对话场景遵守 180 度轴线和正反打逻辑。
8. 每个镜头至少保留一个衔接钩子：动作、视线、声音、构图、道具或情绪。
9. 如果是整页分镜，按用户选择的画布尺寸组织前景、中景、背景和阅读顺序，完整保留对白，不遮挡关键动作。

输出时请把“镜头类型&景别&运镜”“动作细节”“光影氛围”“特效细节”“音效”“时长”“人物”“场景”“画面”“声音”写完整，避免空话和抽象形容词。
```

### 49.2 参考规范接入模板

```text
在不改变原剧情的前提下，结合导演思维和运镜参考库增强分镜。参考库只辅助镜头语言、调度、运镜、空间和节奏，不得替代原文对白和剧情。

优先写法：
1. 先写主体动作和人物关系，再写摄影机运动。
2. 先写视线、遮挡、前景、中景、背景，再写氛围词。
3. 先写动作接点、声音桥、视线匹配，再写转场。
4. 对冲突戏优先正反打、动作匹配、视线匹配。
5. 对悬疑戏优先局部特写、遮挡、慢推、拉远揭示。
```

### 49.3 适合 AI 视频的简化版

```text
把每个镜头拆成：主体运动 + 摄影机运动 + 构图层次 + 声音 + 结束落点。
不要写多个主运镜，不要把多个镜头塞进一条记录，不要删对白。
```

## 51. 现代可控视频生成的共识

从近两年的可控视频研究看，最稳定的做法不是把所有信息塞进一句长提示，而是把控制拆开：

1. **摄影机运动和主体运动分开控制**
   这也是 Direct-a-Video、MotionCtrl、CameraCtrl 的共同方向。对提示词来说，应该把“人物做什么”和“镜头怎么动”分成两句写。

2. **长视频先分 shot，再扩展局部动作**
   DrawVideo、CinePreGen 这类工作都强调 storyboard / keyframe / shot 结构。对分镜提示词来说，最好先让模型完成镜头分段，再在每段里补动作和运镜。

3. **更细的摄影机轨迹比泛化描述更稳**
   “慢推”“横移”“低位跟拍”比“有电影感的运镜”更容易被模型执行。

4. **局部参考比整段强约束更可控**
   对长对白、复杂场景、整页画面，最好把参考规范作为局部辅助上下文，而不是让它覆盖剧情正文。

5. **面向 AI 的分镜要先结构化，再修饰**
   先写镜头目的、主体运动、摄影机运动、空间层次、对白、声音，再补光影和氛围，稳定性远高于直接堆叠形容词。

可直接复用到提示词里的总结句：

```text
把人物运动、摄影机运动、构图层次、对白、声音和转场拆开写；先分 shot，再细化每个 shot 的动作和镜头语言。
```

## 52. 场景类型速查表

| 场景类型 | 导演思维重点 | 常用运镜 | 推荐写法 |
|---|---|---|---|
| 双人对话 | 先定轴线、谁压谁、谁先说服谁 | 正反打、固定、轻微推近 | “保持 180 度轴线，A 说话时镜头压近，B 用反应镜头承接。” |
| 群像围观 | 谁是焦点，谁是背景压力 | 轻跟、慢摇、前景遮挡 | “围观人群作为前景动态，主焦点始终锁定主角。” |
| 线索揭示 | 先局部后全貌，先疑问后答案 | 特写、慢推、拉远 | “先给手机屏特写，再切人物反应，最后拉开空间。” |
| 追逐/移动 | 路线清楚，方向统一 | 跟拍、横移、手持 | “镜头贴着人物侧后方横移跟拍，前景不断掠过。” |
| 压迫/对峙 | 谁在施压，谁在被压 | 低机位、推近、中心构图 | “低机位压住人物，前景遮挡形成包围感。” |
| 孤独/失落 | 让空间比人更大 | 拉远、空镜、负空间 | “角色被放进大面积空白中，环境比人物更重。” |
| 反转/惊吓 | 先藏信息再揭示 | 遮挡、视线匹配、急切推近 | “先给门缝和阴影，下一镜揭示异常主体。” |
| 温情/缓和 | 让动作慢下来，留余韵 | 固定、慢推、柔和跟拍 | “镜头停留更久，让表情和沉默完成情绪。” |
| 调查/推理 | 线索清楚，节奏稳定 | 细节特写、视线匹配、动作匹配 | “道具特写和人物反应交替，信息逐步推进。” |
| 打斗/冲突 | 先看动作路线，再看结果 | 手持、急推、切近景 | “动作切成短镜头，保留出手、闪避、反应和结果。” |

### 52.1 场景写法口诀

```text
对话先轴线，追逐先路线，悬疑先局部，压迫先低位，孤独先空景，反转先遮挡，温情先停顿，冲突先动作。
```

### 52.2 一行模板

```text
[场景类型] + [导演目的] + [主运镜] + [构图关系] + [衔接方式]
```

示例：

```text
双人对话 + 逼迫对方妥协 + 正反打慢推 + 中景压迫构图 + 视线匹配切下一句回应。
```

## 53. 从公开资料转写成 AI 分镜规则

### 53.1 Mise-en-scène：镜头前的一切都要有意义

Mise-en-scène 可以理解为“镜头前被安排出来的一切”：场景、道具、服装、灯光、演员位置、运动和构图。转成 AI 分镜时，不要只写人物，要写清这些元素如何表达剧情。

AI 分镜规则：

```text
每个镜头至少让一个非人物元素承担叙事功能：门、屏幕、灯光、手机、桌面、雨、玻璃、影子、人群、空位。
```

示例：

```text
车厢门不是背景，而是危险边界；陆沉半只脚跨进门线，身后站台人群仍举着手机，门内冷白灯把他和异常空间切开。
```

检查：

- 道具是否推动剧情？
- 灯光是否表达状态？
- 空间是否表达关系？
- 背景是否只是装饰？

### 53.2 Storyboard：画幅比例、镜头顺序和边注同样重要

传统 storyboard 会按最终视频画幅画出每格，并在旁边写镜头说明。转成 AI 漫画/视频提示词时，需要明确：

- 用户选择的画布比例。
- 每一格/每一镜的阅读顺序。
- 镜头运动和声音边注。
- 画面里的主体位置和字幕避让。

AI 分镜规则：

```text
如果用户选择整页尺寸，必须先声明画布比例，再写主视觉中心、阅读路径、前中后景、对白区域和关键线索避让。
```

示例：

```text
9:16 竖屏整页分镜，阅读顺序从下方碎屏手机开始，沿外卖小哥抬头的视线移动到车厢深处僵立乘客；对白放在上方冷白灯空区，不遮挡手机订单界面和小哥嘴部表情。
```

### 53.3 Cinematic techniques：术语要服务表达

常见电影技术包括高低角度、推轨、跟拍、摇臂、深焦、交叉剪辑、跳切、叠化等。AI 分镜里不能只堆术语，要写出每个术语的作用。

错误：

```text
低角度、推轨、深焦、交叉剪辑，画面很震撼。
```

正确：

```text
低角度让陆沉在门口显得更坚定，推轨让他逐渐接近异常空间，深焦同时保留前景大爷和背景车厢乘客，形成“求助者”和“危险源”同框。
```

## 54. 运镜中英术语对照与 AI 写法

| 中文 | 英文常用词 | 适合用途 | AI 写法 |
|---|---|---|---|
| 横摇 | pan | 从一处发现另一处 | “镜头顺着角色视线向右横摇，停在电子屏。” |
| 俯仰摇 | tilt | 从脚到脸、从地面到高处 | “镜头从抓袖子的手向上仰摇到大爷惊恐的脸。” |
| 推轨 / 推近 | dolly in / push in | 情绪加压、靠近线索 | “镜头沿轨道缓慢推向手机屏幕。” |
| 拉远 | dolly out / pull back | 孤立人物、揭示空间 | “从人物近景拉远到整节车厢全貌。” |
| 横移 | truck / track | 跟随移动、展示空间 | “镜头平行横移跟随陆沉挤过人群。” |
| 跟拍 | tracking shot | 主体运动 | “侧后方跟拍，保持人物中景。” |
| 升降 | pedestal / crane | 权力变化、空间规模 | “镜头从人物肩部升高到俯视站台全景。” |
| 手持 | handheld | 现场感、慌乱 | “手持微晃穿过人群，前景频繁遮挡。” |
| 稳定器跟拍 | steadicam / gimbal | 平滑移动、沉浸路线 | “稳定器低位跟拍角色进入车厢。” |
| 变焦 | zoom | 改变画面大小，不改变透视 | “固定机位快速变焦到屏幕文字。” |
| 滑动变焦 | dolly zoom | 眩晕、认知崩塌 | “主体大小不变，背景车厢被拉伸变远。” |
| 转焦 | rack focus | 引导注意力 | “焦点从前景手机转到背景僵立乘客。” |
| 快速横摇 | whip pan | 快速转场、突然发现 | “画面快速横摇成运动模糊，切到人群另一侧。” |
| 环绕 | orbit / arc shot | 关系旋涡、被包围 | “镜头半环绕陆沉，手机屏光围成一圈。” |

## 55. 拉片时应该记录的“时间信息”

很多拉片只记镜头内容，漏了时间。时间决定节奏。

需要记录：

- 镜头时长。
- 运镜起始点和结束点。
- 对白开始和结束。
- 音效是否先于画面。
- 镜头是否在动作前切，还是动作后切。

AI 分镜转写：

```text
镜头 5 秒：前 1 秒固定在碎屏手机，2-4 秒慢推到外卖小哥发抖的嘴唇，第 5 秒停在他说出“确认收货”的表情上。
```

这样比只写“慢推 5 秒”更可执行。

## 56. 画面信息优先级

一个镜头里不要所有信息同等重要。按优先级写：

```text
第一优先级：本镜头必须看懂的剧情动作或对白。
第二优先级：角色表情和情绪。
第三优先级：关键道具、屏幕文字或线索。
第四优先级：空间关系和背景动态。
第五优先级：风格、光影、质感。
```

AI 分镜规则：

```text
先写本镜头必须看懂什么，再写怎么拍。不要先写风格，再补剧情。
```

示例：

```text
本镜头必须看懂：大爷的老伴因“美女图”被困在车厢里。画面先抓住大爷抓袖求助的动作，再完整保留对白，最后用车厢深处冷光提示危险来源。
```

## 57. 镜头覆盖：先保证能剪，再追求好看

coverage 的意思是：一场戏拍够了可以剪的镜头。对 AI 分镜来说，就是一段剧情不要只给一个“漂亮镜头”，而要有能组成剪辑链的覆盖。

### 57.1 最小覆盖组合

一场对话或冲突，至少考虑这些覆盖：

- 建立镜头：交代空间和关系。
- 主体镜头：交代谁在说话、谁在行动。
- 反应镜头：交代情绪变化。
- 细节插入：交代关键道具、屏幕、手势、表情。
- 过渡镜头：交代转场、进出场、视线或动作接点。

AI 写法：

```text
这一场先给车厢门口全景，再给大爷求助中近景，再给陆沉反应近景，再补碎屏手机特写，最后用陆沉看向车厢深处的过渡镜头收束。
```

### 57.2 覆盖不足的典型问题

- 只有主角，没有空间。
- 只有对白，没有反应。
- 只有反应，没有线索。
- 只有特写，没有环境。
- 只有一镜，没有剪辑落点。

### 57.3 Coverage 写进提示词的方式

```text
本段至少覆盖：空间建立、人物对话、反应特写、关键道具特写、转场过渡。
```

### 57.4 适合 AI 的覆盖顺序

```text
空间建立 → 主体行动 → 对白/反应 → 关键道具 → 下一镜钩子
```

## 58. 术语纠错：哪些词最容易写错

### 58.1 Zoom 不等于 Dolly

- `zoom` 是变焦，机位不动。
- `dolly in/out` 是机位物理移动。

AI 写法：

```text
若要压迫感，优先写“慢推”或“推轨”；若要认知扭曲，再考虑“变焦”或“滑动变焦”。
```

### 58.2 Tracking / Truck / Follow

- `tracking shot` 强调跟随主体。
- `truck` 强调摄影机横向移动。
- `follow` 是通俗写法，最好在提示词里写清方向和位置。

AI 写法：

```text
侧后方横移跟拍，不要只写“跟拍”。
```

### 58.3 Whip pan

快速横摇常用于快速转场或突然发现，但不适合每一镜都用。

AI 写法：

```text
只有在突然发现异常、切换场景或制造节奏断裂时使用快速横摇。
```

### 58.4 Rack focus

转焦不是普通虚化，而是把注意力从前景转到背景，或反过来。

AI 写法：

```text
焦点从前景碎屏手机切到背景僵立乘客，让观众沿焦点完成信息读取。
```

### 58.5 Two-shot / OTS / POV

- `two-shot`：两人同框。
- `OTS`：过肩镜头。
- `POV`：主观视角。

AI 写法：

```text
双人对话时优先明确是 two-shot 还是 OTS，不要只写“对话镜头”。
```

## 59. 剧本转分镜时最值得保留的“剪辑钩子”

每个镜头最好留下至少一种钩子，后续方便接下一镜：

- 动作钩子：伸手、回头、起身、推门、停顿。
- 视线钩子：看向门口、电子屏、手机、人物。
- 声音钩子：喇叭声、提示音、脚步、广播。
- 道具钩子：手机、证件、门、杯子、照片。
- 情绪钩子：震惊、迟疑、压抑、崩溃、警觉。
- 构图钩子：门框、前景遮挡、负空间、中心构图。

AI 写法：

```text
这一镜结尾让陆沉的视线停在电子屏左上角，下一镜直接切屏幕特写。
```

```text
大爷的手最后仍攥着陆沉袖口，下一镜从手部特写切到陆沉的反应。
```

## 60. 最终输出前的五问

在把分镜交给 AI 前，先问自己：

1. 这一镜最重要的信息是什么？
2. 这一镜里谁在动，摄影机怎么动？
3. 这一镜的对白有没有逐字保留？
4. 这一镜和下一镜靠什么连接？
5. 这一镜有没有把剧情写完、把线索写清、把动作写实？

如果五问里有一条答不上来，就说明镜头还不够稳。

## 61. 可直接拼接的提示词片段库

### 61.1 悬疑开场

```text
先给局部异常，再给人物反应，最后拉开空间揭示全貌；镜头保持克制，不要一次把答案全讲完。
```

```text
使用低机位、慢推、前景遮挡和画外声，先制造疑问，再用下一镜给出线索。
```

### 61.2 双人对话

```text
保持 180 度轴线统一，采用正反打和过肩镜头；说话人镜头里要保留足够的表情变化和停顿，不要把长对白塞进一个镜头。
```

```text
一方说话时，另一方用反应镜头承接；视线匹配和动作匹配要清楚。
```

### 61.3 群像围观

```text
前景用举手机的人群制造遮挡和压力，中景保留主角动作，背景交代空间规模；围观者只做动态背景，不抢主角焦点。
```

### 61.4 追逐/移动

```text
镜头侧后方横移跟拍，保持主体始终可见；前景掠过制造速度感，背景透视连续，动作路线必须清楚。
```

### 61.5 冲突爆发

```text
先给压迫性的低机位中近景，再给手部、脸部和道具特写，最后用反应镜头收尾；动作切成短镜头，保留出手、躲避、停顿和结果。
```

### 61.6 温情缓和

```text
镜头放慢，固定或轻微慢推，让表情和沉默完成情绪；环境声保留，避免过度炫技运镜。
```

### 61.7 反转揭示

```text
先隐藏关键对象，通过门缝、屏幕边缘、前景遮挡或视线引导逐步揭示；揭示瞬间切到特写或反应镜头。
```

### 61.8 整页画面

```text
按用户选择的画布比例组织前景、中景、背景和阅读路径；对白和字幕放在空区，不遮挡关键动作和关键道具。
```

### 61.9 AI 视频控制

```text
把主体运动、摄影机运动、构图层次、声音和结束落点拆开写；不要把多个主运镜写进同一镜，也不要混淆人物动作和镜头动作。
```

### 61.10 最终拼接示例

```text
这一场先交代空间，再推进人物动作，再给反应和线索特写；对话遵守 180 度轴线，镜头用正反打和视线匹配连接，必要时用前景遮挡和声音桥完成转场。
```

## 62. 多镜头一致性：剧本转分镜必须提前考虑“后续能不能接”

近年的多镜头 AI 视频研究普遍强调：长视频不能只靠一个长提示词，必须先拆成 shot / storyboard / keyframe，再维护镜头间的一致性。对剧本转分镜来说，这意味着每个分镜不仅要好看，还要能接到前后镜。

### 62.1 一致性要素

| 一致性类型 | 要保持什么 | 分镜写法 |
|---|---|---|
| 角色一致性 | 服装、年龄、发型、体型、道具 | “陆沉始终穿深色外套，右手护着黑色工具包。” |
| 空间一致性 | 门、屏幕、站台、人群的相对位置 | “电子屏始终位于站台上方右侧，车厢门在画面后方中央。” |
| 光影一致性 | 主光源、色温、屏幕光方向 | “全场保持地铁冷白顶光，手机屏蓝白补光来自下方。” |
| 动作连续性 | 上一镜动作是否在下一镜延续 | “承接上一镜抓袖动作，下一镜手指已攥紧布料。” |
| 情绪连续性 | 角色情绪是否有递进 | “大爷从焦急求助转为恐惧回忆，不要突然恢复平静。” |
| 道具连续性 | 手机、证件、工具包、屏幕信息是否前后一致 | “碎屏手机始终显示外卖订单界面和低电量提示。” |

### 62.2 分镜里要写“镜头间记忆”

可直接加入提示词：

```text
每个镜头必须继承上一镜的人物位置、道具状态、光影方向和情绪状态；如果发生变化，必须在动作细节中写出变化过程。
```

示例：

```text
上一镜大爷已经抓住陆沉袖口，本镜头不能让两人突然分开；必须承接抓袖动作，并让陆沉低头看向被抓住的袖子。
```

## 63. 关键帧思维：每个镜头至少要有起点和终点

多镜头视频生成常用 start frame / end frame 或 keyframe 来控制动作。写分镜时也应该为每个镜头设计“起点状态”和“终点状态”。

### 63.1 起点-终点模板

```text
起点：镜头开始时主体在哪里，做什么，画面构图是什么。
过程：主体动作和摄影机运动如何推进。
终点：镜头结束时停在哪个表情、道具、空间或动作上，为下一镜留下钩子。
```

### 63.2 示例

```text
起点：陆沉站在车厢门外，半侧脸被站台冷光照亮。
过程：镜头从他侧后方慢慢推近，他的视线越过大爷看向电子屏。
终点：镜头停在陆沉眼神收紧的近景，为下一镜切电子屏特写做准备。
```

### 63.3 避免无终点镜头

失败：

```text
陆沉看着车厢，气氛紧张。
```

修正：

```text
陆沉看向车厢深处，眼神从警觉转为确认；镜头最后停在他按住工具包锁扣的手上，下一镜切工具包特写。
```

### 63.4 关键帧选择规则

每个镜头至少选两个关键帧：

```text
起始关键帧：交代人物位置和空间关系。
结束关键帧：留下下一镜可以承接的动作、视线、道具或情绪。
```

复杂动作可以选三个关键帧：

```text
起点：人物刚开始动作。
中点：动作最清楚或冲突最强的瞬间。
终点：动作完成并留下转场钩子。
```

AI 视频写法：

```text
起始关键帧为陆沉站在车厢门外，中间关键帧为他被大爷抓住袖子，结束关键帧为他抬眼看向电子屏。
```

## 64. 镜头转场类型库

| 转场类型 | 适合场景 | 分镜写法 |
|---|---|---|
| 硬切 | 冲突、惊吓、信息突变 | “在提示音响起瞬间硬切手机特写。” |
| 动作切 | 连续动作、走位、抓取 | “伸手动作跨镜完成，切点藏在手部运动中。” |
| 视线切 | 角色发现线索 | “陆沉看向右上方，下一镜切电子屏。” |
| 声音先行 | 先制造悬念或空间感 | “工作人员喊声先入，画面仍停在车厢死寂中。” |
| 图形匹配 | 诗意转场、线索联想 | “手机裂纹切到车门玻璃裂状反光。” |
| 遮挡切 | 人群、门框、快速移动 | “前景手机屏划过遮满画面，切到下一镜。” |
| 拉黑/留白 | 章节结束、情绪收束 | “地铁灯闪烁后短暂黑场，进入下一场。” |

提示词约束：

```text
每个镜头结尾必须明确转场方式，至少选择动作、视线、声音、图形、遮挡、情绪中的一种。
```

## 65. 多镜头叙事的节奏控制

视频研究中的 narrative pacing control 可以转成剧本转分镜的节奏规则：不同剧情节点不要平均用力。

### 65.1 节奏分配

| 剧情节点 | 镜头策略 |
|---|---|
| 开场钩子 | 少解释，多局部特写和异常反应 |
| 交代空间 | 给建立镜头，但不要拖太久 |
| 对话解释 | 拆正反打，保留反应和道具特写 |
| 线索出现 | 单独给特写和反应镜头 |
| 情绪爆点 | 镜头更短，景别更近，声音更强 |
| 余韵收束 | 镜头更稳，允许空镜和环境声 |

### 65.2 避免平均节奏

失败：

```text
每个镜头都是 5 秒中景，人物说话，固定镜头。
```

修正：

```text
普通过渡镜头 3-4 秒；关键对白 5-6 秒；线索特写 3 秒；情绪爆点用短镜头快速切换；收束镜头固定停留 5-6 秒。
```

## 66. 针对剧本转分镜插件的建议接入方式

为了让本参考库更好地服务插件，建议不要把整篇文档直接塞进剧情正文，而是作为独立参考参数或系统上下文使用。

### 66.1 推荐接入

```text
screenplay_reference = 导演思维运镜.md 的摘要或局部章节
输入文案 = 用户剧情正文
```

### 66.2 每次只取相关章节

如果剧情是对话戏，重点取：

- 轴线。
- 正反打。
- 反应镜头。
- 对白完整性。
- 视线匹配。

如果剧情是悬疑开场，重点取：

- 局部异常。
- 遮挡揭示。
- 慢推。
- 声音先行。
- 空间拉远。

如果剧情是整页画面，重点取：

- 画布比例。
- 阅读路径。
- 前中后景。
- 文字避让。
- 关键动作完整。

### 66.3 最小注入片段

```text
参考导演思维运镜库，但只用于增强镜头语言和衔接，不得改写剧情。每条记录一个镜头；对白逐字保留；主体运动和摄影机运动分开写；每镜保留起点、过程、终点和转场钩子。
```

## 67. Coverage 深化：给剪辑留下选择，而不是只给一个“能看”的镜头

公开电影制作资料里，coverage 的核心价值是给剪辑提供足够素材。剧本转分镜也一样：如果分镜只生成主动作，没有反应、插入、过渡和清洁切点，后续视频生成再漂亮也很难剪。

### 67.1 一场戏的 coverage 最小包

```text
Master / Establishing：交代场景、人物关系、空间方向。
Medium：承载主要对白和动作。
Close-up：承载情绪、关键反应、重要表情。
Insert / Cut-in：关键道具、屏幕文字、手部动作。
POV：角色看到的线索或威胁。
Reaction：角色或人群对信息的反应。
Transition：进入或离开场景的动作、声音、遮挡、空镜。
```

AI 分镜规则：

```text
一段剧情至少要覆盖“空间-行动-反应-线索-转场”五类镜头，不要只输出连续主镜头。
```

### 67.2 Clean frame / 切点预留

剪辑需要镜头开头和结尾留一点空间，不能所有动作都顶着边界开始和结束。

AI 写法：

```text
镜头开始先固定半秒在车厢门口，再让陆沉入画；结尾在他按住工具包锁扣后停留半秒，为下一镜切特写预留切点。
```

### 67.3 Cutaway / 插入镜头的作用

插入镜头不是凑数，它能解决：

- 补线索。
- 遮盖剪辑。
- 调整节奏。
- 给观众反应时间。
- 从人物转到环境。

AI 写法：

```text
插入碎屏手机低电量提示特写，作为外卖小哥焦虑的具体原因，同时给下一句对白提供节奏停顿。
```

### 67.4 POV 和反应必须成对

如果给角色主观视角，最好接反应；如果先给反应，下一镜要解释他看到了什么。

```text
POV：陆沉视角看见电子屏热搜。
Reaction：切陆沉近景，他眼神收紧，手指按住工具包锁扣。
```

## 68. Storyboard 深化：每格不是插画，而是剪辑单位

Storyboard 的价值不是画得漂亮，而是提前定义“观众会按什么顺序看到什么”。AI 分镜可以借用这个逻辑。

### 68.1 每格必须包含技术边注

```text
画幅比例：
镜头编号：
景别/机位：
主体位置：
主体运动：
摄影机运动：
声音/对白：
转场方式：
时长：
```

正式输出时不一定显示这些边注，但内部提示词必须让 AI 理解这些要素。

### 68.2 Thumbnail 到精细分镜

先小缩略思考，再扩写镜头：

```text
缩略：手机特写 → 外卖小哥求助 → 车厢全貌
扩写：每个缩略点补景别、机位、动作、对白、光影、声音、转场。
```

这能避免 AI 一开始就写很多漂亮词，却漏掉镜头顺序。

### 68.3 每格要有“视觉重心”

```text
这一格第一眼看哪里？
第二眼看哪里？
对白和线索会不会抢位置？
人物动作是否被遮挡？
```

AI 写法：

```text
视觉重心放在外卖小哥发抖的嘴唇和碎屏手机之间，背景车厢乘客只作为第二阅读层出现。
```

## 69. 从剧本到分镜的四步流水线

建议 AI 剧本转分镜内部按以下顺序执行：

### 69.1 第一步：提取不可遗漏项

```text
人物：
地点：
动作：
对白：
屏幕文字：
关键道具：
情绪转折：
必须展示的因果：
```

### 69.2 第二步：按节拍切 shot

```text
一个镜头只承担一个主要节拍：
发现、反应、行动、对白、线索、转折、结果。
```

### 69.3 第三步：给每个 shot 选导演策略

```text
这个 shot 是交代空间、推进动作、表达情绪、揭示线索、强化冲突，还是转场？
```

### 69.4 第四步：补技术参数

```text
景别、机位、运镜、构图、光影、声音、时长、转场钩子。
```

最终提示词片段：

```text
先提取原文所有不可遗漏项，再按剧情节拍切 shot；每个 shot 只承担一个主要叙事功能，然后补景别、机位、主体运动、摄影机运动、光影、声音和转场。
```

## 71. 导演现场决策矩阵

真实拍摄不是先选漂亮镜头，而是先回答导演问题。AI 分镜也应该按这个矩阵推理：

| 导演问题 | 如果答案是 | 镜头策略 |
|---|---|---|
| 观众现在需要知道什么？ | 地点/关系 | 建立镜头、全景、深焦 |
| 观众现在需要感受什么？ | 压迫/恐惧/孤独 | 低机位、负空间、慢推、遮挡 |
| 谁掌握主动权？ | A 逼迫 B | A 用低角度或居中，B 用高角度或边缘构图 |
| 谁的信息更多？ | 观众多于角色 | 先给线索，再给角色未察觉 |
| 情绪要升还是降？ | 升 | 推近、切近景、声音增强 |
| 是否需要隐藏答案？ | 是 | 局部特写、前景遮挡、画外声 |
| 下一镜怎么接？ | 动作/视线/声音 | 在本镜结尾预留对应钩子 |

可直接写入提示词：

```text
每个镜头先回答“观众此刻需要知道什么、感受什么、谁掌握主动权、下一镜靠什么接”，再选择景别、机位和运镜。
```

## 72. 多镜头 AI 生成的新结论：转场也要被设计

ShotDirector、Camera Artist、Mind-of-Director 等近期研究都指出，多镜头视频的问题不只是单镜头质量，而是镜头之间缺少导演式转场和叙事连续性。剧本转分镜要提前写出转场意图。

### 72.1 不要只写“下一个镜头”

失败：

```text
镜头1：陆沉看电子屏。
镜头2：电子屏特写。
```

修正：

```text
镜头1结尾：陆沉抬眼看向画面右上方电子屏，眼神收紧。
转场：视线匹配硬切。
镜头2开头：电子屏热搜标题占满画面，滚动光效继续。
```

### 72.2 转场提示词最小结构

```text
上一镜结尾动作/视线/声音/图形 → 转场方式 → 下一镜开头落点
```

示例：

```text
大爷颤抖手指指向车厢深处 → 动作匹配切 → 车厢内僵硬手指握着手机的特写。
```

### 72.3 镜头间叙事连续性

```text
相邻镜头必须继承人物状态、道具位置、空间方向、光影色温和情绪强度；若发生变化，必须写出变化过程。
```

## 73. Actor-Camera Sync：摄影机要和演员状态同步

虚拟摄影机控制研究强调，摄影机运动最好与演员的身体动作和心理状态同步。对 AI 分镜来说：

| 演员状态 | 摄影机策略 |
|---|---|
| 犹豫、观察 | 固定、慢推、浅景深 |
| 快速移动 | 跟拍、横移、手持 |
| 情绪崩溃 | 近景、轻微手持、声音抽离 |
| 权力增强 | 低机位、推近、中心构图 |
| 被压迫 | 高机位、负空间、前景遮挡 |
| 意识到真相 | 慢推到眼睛、转焦到线索、声音压低 |

AI 写法：

```text
摄影机运动随角色心理变化：陆沉听到“美女图”前保持平稳中景，听到关键词后镜头慢推到眼睛，背景声音压低，表现他进入判断状态。
```

## 74. 拉片到提示词的转译流程

把任意拉片资料转成提示词，不要保留电影名和具体桥段，而要提炼成规则。

```text
原片镜头现象：
导演意图：
可迁移规则：
适用场景：
AI 提示词句式：
反例：
```

示例：

```text
原片镜头现象：角色看向画外，下一镜揭示目标。
导演意图：让观众跟随角色视线获取信息。
可迁移规则：视线匹配适合线索揭示、威胁出现、人物进入。
适用场景：悬疑、调查、反转、发现异常。
AI 提示词句式：角色视线停在画面右上方，下一镜用视线匹配切到该方向的关键线索。
反例：角色没有明确看向目标，却突然切线索，会显得突兀。
```

## 77. 失败模式表

| 失败模式 | 为什么会坏 | 修正方式 |
|---|---|---|
| 一条记录写多个镜头 | 下游无法稳定拆分 | 一条记录只写一个镜头，编号全局递增 |
| 只写术语不写动作 | 模型不会执行 | 每个术语后面补具体动作、位置、光影 |
| 只写风格不写剧情 | 会丢情节 | 先写必须看懂的动作和对白，再写风格 |
| 运镜写太多 | 镜头互相打架 | 一个主运镜 + 一个辅助运动就够 |
| 对话没轴线 | 正反打会乱 | 先定 180 度轴线，再切镜 |
| 没有转场钩子 | 下一个镜头不好接 | 结尾固定给动作、视线、声音或道具钩子 |
| 没有覆盖 | 只能看不能剪 | 增加建立镜头、反应、插入、过渡 |
| 参考资料混进剧情 | 剧情会被污染 | 参考作为独立参数，不写进正文 |
| 时间信息缺失 | 节奏失控 | 给每个镜头写时长或快慢节奏 |
| 画幅没写 | 整页画面会乱 | 先写画布比例和阅读路径 |

### 77.1 失败示例到修正示例

```text
失败：镜头很有电影感，运镜丰富，氛围紧张。
修正：低机位慢推到陆沉眼睛，前景手机屏掠过，背景车厢门和僵立乘客形成压迫。
```

```text
失败：陆沉看电子屏，下一镜切热搜。
修正：陆沉先抬眼看向画面右上方电子屏，下一镜用视线匹配切到热搜标题特写。
```

```text
失败：把大爷的对白压成一句“我老伴出事了”。
修正：保留完整对白，再用动作和表情补强情绪，不删句子。
```

## 78. 句子级 shot 写法：一镜一意，一镜一句

The Prose Storyboard Language 这类研究强调：shot 级描述最好是机器和人都能读懂的短句，而不是混合长段落。对 AI 分镜来说，最稳的做法是“每个镜头一条主句，再附若干短补充句”。

### 78.1 句法规则

```text
镜头主句 = [镜头目的] + [主体动作] + [摄影机运动] + [落点]
```

补充句只允许加入：

- 表情。
- 光影。
- 声音。
- 道具状态。
- 转场钩子。

### 78.2 示例

```text
陆沉逆着人群挤进站台，镜头在他侧后方横移跟拍，最终停在他抬眼看向电子屏的瞬间。
```

```text
大爷抓住陆沉袖子急促求助，镜头从中景慢推到近景，最后停在他发白的指节上。
```

### 78.3 不推荐的写法

```text
陆沉挤进人群，听到大爷求助后转头看电子屏，想到老伴出事，决定进去，镜头又推又摇又跟，画面还很压迫。
```

问题：

- 一个镜头写了多个节拍。
- 运镜堆叠。
- 心理过程和动作混成一条。

### 78.4 一镜一句的好处

- 便于模型拆分。
- 便于下游解析。
- 便于人工审查。
- 便于对比原文对白是否缺失。

## 80. 镜头句子压缩规则

为了让 AI 更稳，长镜头句子要压缩成“短主句 + 短补句”。

### 80.1 压缩前

```text
陆沉从人群里挤进站台，前景不断有手机掠过，工作人员拿着喇叭喊别拍，远处电子屏上还亮着热搜，整个车厢的人都僵在那里。
```

### 80.2 压缩后

```text
陆沉逆着人群挤进站台，镜头侧后方横移跟拍，前景手机掠过形成遮挡。

工作人员的喇叭声先行响起，下一镜切到电子屏热搜特写。

车厢深处僵立乘客被拉远揭示，形成异常全貌。
```

### 80.3 压缩准则

- 一句只保留一个核心动作。
- 一句只保留一个主要运镜。
- 一句只保留一个主要信息点。
- 复杂场景拆成连续短句，不拆对白。

## 81. 最新资料摘要：对本项目最有用的四条结论

1. **Coverage** 不是可有可无，而是为了给剪辑留建立、反应、插入和过渡镜头。
2. **Storyboard** 本质上是按画幅和节拍组织的 shot 序列，不是单张插画。
3. **多镜头生成** 必须关注镜头间一致性、角色记忆和转场方式。
4. **导演思维** 在 AI 里最有价值的不是术语本身，而是“为什么此刻必须这样拍”。

### 81.1 可直接写进提示词的一段总结

```text
把剧本先拆成不可遗漏项，再按剧情节拍切 shot；每个 shot 只承担一个主要目的，写清主体动作、摄影机运动、构图、声音和转场钩子，并保证上一镜和下一镜在人物状态、道具位置、光影方向和空间关系上连续。
```

## 82. 光线叙事：灯光不是美化，是信息控制

摄影资料里常把灯光作用归为可见性、构图和情绪。AI 分镜也应按这三层写光线。

### 82.1 可见性

光首先让观众看清关键内容：

```text
手机屏幕蓝白光照亮碎裂界面和外卖订单，确保“低电量”和订单状态清晰可见。
```

### 82.2 构图

光线引导观众看哪里：

```text
车厢顶灯只照亮乘客僵硬的下半张脸，眼睛藏在阴影里，让观众先注意手机屏幕和嘴唇状态。
```

### 82.3 情绪

光线表达心理和类型：

```text
冷白荧光和手机蓝光叠加，人物肤色发灰，环境像被抽走温度，强化异常和疏离。
```

### 82.4 Practical light / 现场光源

AI 更容易理解有来源的光：

- 手机屏。
- 电子屏。
- 车厢顶灯。
- 路灯。
- 台灯。
- 闪烁警示灯。

写法：

```text
以电子屏为主光源，蓝白光从上方打在陆沉侧脸，站台顶灯作为冷白补光，背景人群被压暗。
```

### 82.5 三点布光的提示词化

不必在每个镜头都写“key/fill/back light”，但可转成中文：

```text
主光来自车厢顶灯，弱补光来自手机屏，背后站台灯勾出陆沉肩线。
```

## 83. 交叉剪辑和平行叙事

交叉剪辑用于在两个行动之间来回切，制造同时发生、对比或紧张感。短剧和悬疑里很常用。

### 83.1 适用场景

- 一边有人求助，一边危险正在扩大。
- 一边主角赶路，一边反派准备行动。
- 电话两端对话。
- 多个地点同时发生相关事件。
- 时间倒计时。

### 83.2 AI 分镜写法

```text
在外卖小哥求助和车厢内僵立乘客之间交叉剪辑：每次切回车厢，手机屏光更强，异常范围更明确。
```

### 83.3 节奏控制

```text
开始用较长镜头交代两边空间，随后镜头越来越短，切换频率加快，直到两条行动线在同一地点汇合。
```

### 83.4 避免误用

不要在没有并行动作的情况下强行交叉剪辑。否则会像乱切。

## 84. Montage / 蒙太奇压缩

蒙太奇适合压缩时间、展示信息累积、表现心理联想。它不是乱剪素材，而是通过连续镜头建立新意义。

### 84.1 适用

- 搜索线索。
- 时间流逝。
- 舆论发酵。
- 多人同时受到影响。
- 角色快速整理证据。

### 84.2 AI 分镜写法

```text
蒙太奇段落：多个手机屏幕连续闪过同一张打码照片，站台不同角落的人群同时停下动作，电子屏热搜数字不断上升，低频音效逐渐增强。
```

### 84.3 检查

```text
这些镜头是否共同表达一个更大的意义？
是否只是素材堆叠？
是否仍保留核心剧情线索？
```

## 85. Lighting + Editing 的组合用法

光线和剪辑可以一起工作：

```text
手机屏闪烁一次 → 硬切到另一个人手机屏。

## 87. 不同题材的镜头优先级

### 87.1 悬疑 / 惊悚

优先级：

```text
局部异常 > 反应 > 空间全貌 > 光影不安 > 声音压迫
```

### 87.2 对话 / 关系戏

优先级：

```text
轴线 > 表情变化 > 正反打 > 语气停顿 > 视线匹配
```

### 87.3 动作 / 追逐

优先级：

```text
路线清楚 > 主体动作 > 摄影机跟随 > 遮挡和前景掠过 > 速度感
```

### 87.4 群像 / 场面戏

优先级：

```text
空间层次 > 主角焦点 > 群体反应 > 群体流动 > 背景秩序
```

### 87.5 温情 / 慢节奏

优先级：

```text
停顿 > 表情 > 环境声 > 柔和构图 > 少量慢推
```

### 87.6 反转 / 爆点

优先级：

```text
钩子 > 反应 > 揭示 > 声音变化 > 下一镜预埋
```

### 87.7 整页画面

优先级：

```text
主视觉中心 > 阅读路径 > 对白避让 > 前中后景 > 风格修饰
```

### 87.8 一行通用规则

```text
不同题材先保留该题材最重要的镜头优先级，再补风格；不要反过来。

## 88. 题材专用提示词段落

### 88.1 悬疑 / 惊悚

```text
按“局部异常 → 人物反应 → 空间全貌”的顺序组织镜头。优先使用局部特写、前景遮挡、慢推、声音先行和拉远揭示；不要一开始就把异常全貌解释完。
```

### 88.2 对话 / 关系戏

```text
先确定 180 度轴线和人物左右关系，再用正反打、过肩镜头和反应镜头推进对白。长对白可以拆成连续镜头，但对白内容必须逐字完整保留。
```

### 88.3 动作 / 追逐

```text
先交代运动路线，再写主体动作和摄影机跟随。每个镜头只承担一个动作阶段，使用跟拍、横移、前景掠过和动作匹配剪辑保持方向清楚。
```

### 88.4 群像 / 场面戏

```text
先确定主角焦点，再把人群分成前景遮挡、中景互动、背景规模三层。群体动态只服务主角和事件，不要让所有人平均抢戏。
```

### 88.5 温情 / 慢节奏

```text
镜头以固定、慢推和柔和跟拍为主，给表情、停顿、手部动作和环境声留时间。不要用过多快速运镜打断情绪。
```

### 88.6 反转 / 爆点

```text
先埋钩子，再给反应，最后揭示答案。反转镜头要单独给关键道具、屏幕文字或证据特写，并在下一镜保留人物反应。
```

### 88.7 整页漫画 / 整页分镜

```text
先按用户选择的画布比例设定主视觉中心和阅读路径，再安排前景、中景、背景和对白区域。所有对白完整保留，文字避开眼睛、嘴部表情、关键动作和关键道具。
```

### 88.8 AI 视频生成

```text
每个镜头只写一个主动作和一个主运镜。把主体运动、摄影机运动、构图层次、光影来源、声音和结束落点分开写，避免一个镜头同时推拉摇移跟环绕。
```

## 90. 从剧情到分镜的最简工作流

这是给 AI 剧本转分镜最稳的执行顺序：

```text
1. 先提取不可遗漏项：人物、动作、对白、屏幕文字、道具、地点、转折。
2. 再按剧情节拍切 shot：一个 shot 只承担一个主要目的。
3. 给每个 shot 判断导演目的：交代空间、推进动作、表达情绪、揭示线索、强化冲突、转场。
4. 选择镜头策略：景别、机位、构图、调度、运镜、焦距、光影。
5. 写主体运动：人物做什么，从哪里到哪里，动作起点和终点。
6. 写摄影机运动：镜头从哪里拍，怎么动，速度如何，落到哪里。
7. 写声音和对白：对白逐字保留，环境声和音效服务转场。
8. 写连续性：继承上一镜人物状态、道具位置、光影方向和情绪。
9. 写转场钩子：动作、视线、声音、构图、道具或情绪。
10. 输出前自检：一条记录一个镜头，编号递增，剧情和对白无遗漏。
```

一句话版本：

```text
先保剧情，再分节拍；先定目的，再选镜头；先写动作，再写运镜；先保对白，再补风格；先做连续性，再输出。
```

## 94. 术语使用优先级

为了让中文模型更稳定，术语建议按以下优先级使用：

```text
中文专业术语 > 中文解释性短句 > 英文术语补充 > 抽象形容词
```

推荐：

```text
正反打对话镜头，保持 180 度轴线统一。
```

也可：

```text
过肩镜头（OTS），从陆沉肩后看向大爷。
```

不推荐：

```text
cinematic shot, dramatic camera, cool movement。
```

规则：

- 中文主导，英文只做补充。
- 术语后必须跟具体画面动作。
- 不要用英文术语掩盖缺失的调度和动作。

## 95. 文字、字幕和对白避让

AI 漫画和短视频分镜里，文字经常遮挡关键表情或线索。写分镜时要提前指定文字区域。

### 95.1 不能遮挡的位置

- 人物眼睛。
- 嘴部表情。
- 手部关键动作。
- 手机屏幕。
- 证件、门牌、热搜标题、订单界面等关键文字。
- 道具交接点。

### 95.2 推荐写法

```text
对白文字放在画面上方冷白灯空区，不遮挡外卖小哥嘴部表情和碎屏手机订单界面。
```

```text
屏幕文字单独给特写，确保热搜标题清晰可读，避免背景人群遮挡。
```

### 95.3 整页画面推荐

```text
先确定主视觉中心，再把对白放到视觉路径外侧；文字区域服务阅读顺序，不抢线索和人物表情。
```

## 96. 已核验来源要点

### 96.1 CameraCtrl

要点：面向文生视频的摄影机姿态控制，支持“摄像机运动本身是叙事语言”的判断。
可迁移到提示词：把摄影机运动写得更具体，例如低位跟拍、横移、慢推、拉远揭示，而不是写“高级运镜”。

### 96.2 MotionCtrl

要点：明确区分 camera motion 和 object motion。
可迁移到提示词：每个镜头都要分开写“人物/物体怎么动”和“摄影机怎么动”。

### 96.3 Direct-a-Video

要点：支持用户分别指定对象运动和摄影机运动。
可迁移到提示词：主体运动、摄影机运动、构图落点应独立成句，避免混写。

### 96.4 ShotDirector

要点：多镜头生成不能只关注视觉一致性，还要关注有导演意图的转场和剪辑模式。
可迁移到提示词：每个镜头结尾必须写动作、视线、声音、图形或遮挡转场钩子。

### 96.5 Camera Artist

要点：递归 storyboard 和 cinematic language 能提升相邻镜头叙事连续性。
可迁移到提示词：先做 shot-to-shot 连续，再写单镜头细节。

### 96.6 Prose Storyboard Language

要点：用可读的 prose/shot 级语言标注和导演电影。
可迁移到提示词：一镜一意、一镜一句，避免长段落混多个镜头。

## 97. Coverage 镜头覆盖：给剪辑留余地

真实导演分镜不是只写“最终会出现的画面”，还要考虑剪辑能不能成立。AI 剧本转分镜也应把 coverage 思维写进去：一个场景至少要有主镜头、动作或对白重点、反应镜头、细节插入、转场钩子。

### 97.1 最小 coverage 组合

```text
1. 主镜头：交代空间、人物位置、核心冲突。
2. 中近景：承接主要对白或动作，保持情绪可读。
3. 反应镜头：给听者、旁观者或受影响者表情。
4. 插入镜头：关键道具、手机屏幕、手部动作、证据、门牌、金额、伤口等。
5. 切出镜头：环境、人群、监控、窗外、灯光变化等，用于压缩时间或遮挡剪辑。
6. 过渡镜头：用视线、动作、声音、物体运动或图形相似进入下一场。
```

### 97.2 AI 分镜转写规则

- 不要只写一个“很好看的大全景”；剧情需要剪辑点。
- 主镜头负责“这是谁在哪里发生什么”，近景负责“人物此刻怎么变”，插入镜头负责“观众必须看到的线索”。
- 对话场景必须保留说话者、听话者、双人关系和反应镜头；只写台词画面会让剪辑缺少情绪落点。
- 动作场景必须补足因果链：准备动作、动作发生、动作结果、他人反应。
- 关键道具不能只在台词中出现，必须至少给一次视觉确认。

### 97.3 可直接加入插件的提示词

```text
请按 coverage 思维拆分分镜。每个场景至少包含：空间交代镜头、主要动作/对白镜头、反应镜头、关键道具或线索插入镜头、用于连接下一镜头的转场钩子。不得遗漏剧本中的对白、关键动作、因果线索和情绪变化。
```

## 98. 多镜头连续性记忆：防止角色和空间漂移

近年的多镜头 storyboard 与叙事视频生成资料都强调：连续性不能只靠单镜头美感，需要跨镜头的身份、空间、动作和情绪记忆。插件可以在剧本转分镜时先生成一份“连续性记忆表”，再逐镜头调用。

### 98.1 连续性记忆表字段

```text
角色记忆：姓名、年龄感、发型、服装、标志物、当前情绪、与其他人的站位关系。
空间记忆：场景名称、入口/出口、主要家具、光源方向、镜头轴线、人物起止位置。
道具记忆：道具名称、所属人物、当前状态、是否必须特写、是否影响剧情。
动作记忆：上一个镜头结束姿势、下一个镜头起始姿势、动作方向、速度、是否连续。
情绪记忆：上一镜情绪、情绪转折点、下一镜必须呈现的表情或身体反应。
转场记忆：用什么元素衔接下一镜，是否需要匹配动作、匹配视线、匹配图形或声音桥。
```

### 98.2 写入 shot 的方式

推荐每个镜头保留短字段：

```text
连续性：承接上一镜“林夏握紧碎屏手机、站在便利店门口右侧”的动作；本镜结束于她抬头看见监控摄像头，为下一镜监控特写做视线转场。
```

不推荐：

```text
保持连续性，画面电影感强。
```

### 98.3 一整页分镜的特殊规则

如果一个分镜是一整页，尺寸由用户选择后固定；但固定尺寸不代表压缩剧情。应优先完整呈现剧情动作、对白和因果线索，再考虑画面装饰。

```text
整页分镜必须先确定阅读顺序、主视觉中心、人物动线和对白区域。不得因为构图漂亮而省略对白、关键动作或剧情线索；必要时允许增加画面说明篇幅，用文字把动作和情节完整交代清楚。
```

## 100. 插件落地优先级

如果只能选少量规则接入插件，优先级如下：

```text
P0 必须接入：
1. 不遗漏对白、动作、因果线索。
2. 一镜一意，主体运动和摄影机运动分开写。
3. 整页分镜尺寸由用户选择并固定。
4. 每个场景输出 coverage：主镜头、动作/对白、反应、插入、转场钩子。

P1 强烈建议：
1. 生成角色/空间/道具/动作连续性记忆表。
2. 每镜增加“剧情功能”和“观众注意点”字段。
3. 对话场景自动检查 180 度轴线、视线匹配和正反打关系。
4. 动作场景自动检查准备、发生、结果、反应是否齐全。

P2 可逐步增强：
1. 根据题材选择镜头风格库。
2. 根据用户选择输出漫画页、短视频分镜、影视分镜、动画 storyboard。
3. 支持把专业镜头语言规范作为 reference 注入。
4. 支持输出短版/长版两种提示词。
```

最终建议：先把 P0 和 P1 做成固定系统提示词，再把 P2 做成可选开关。这样既能稳定质量，也不会让普通用户被专业术语压住。

## 101. 观众视线：镜头设计的隐藏主线

导演思维的核心不是“镜头多专业”，而是控制观众注意力：这一秒看谁、下一秒看什么、为什么转移、转移后获得什么信息。拉片时要记录观众视线如何被构图、运动、光线、声音和剪辑牵引。

### 101.1 视线控制工具

```text
构图：把人物、道具或动作放到视觉权重最高的位置。
焦点：用浅景深、拉焦、清晰/模糊对比引导注意。
运动：让唯一移动的元素成为视觉中心。
光线：用亮部、阴影、色温差异提示重点。
声音：用声源、停顿、异响或声音桥提前指向下一画面。
剪辑：在观众已经想看下一个信息点时切过去。
遮挡：让主体从遮挡后出现，制造揭示感。
反应：用听者或旁观者表情告诉观众“这句话产生了什么后果”。
```

### 101.2 AI 分镜必须写“注意点”

建议每个镜头增加字段：

```text
观众注意点：观众首先看见林夏手里的碎屏手机，其次看到屏幕上的未接来电，最后被她抬头看向监控的动作带到下一镜。
```

这样能减少两个问题：

- AI 画面里所有元素同等抢戏，主线不清。
- 镜头之间缺少视线钩子，分镜像图片列表而不是叙事。

### 101.3 拉片时记录注意力转移

```text
时间点：00:12-00:18
观众先看：人物眼神
被什么引导：人物突然停顿和背景门铃声
随后看向：门口阴影
获得信息：有人进入，但身份未揭示
下一镜如何承接：切门把手特写，悬念具体化
```

### 101.4 插件提示词片段

```text
每个分镜必须写明观众注意点：观众先看什么、为什么会看那里、下一步注意力被什么动作/声音/光线/剪辑转移。镜头设计必须服务剧情信息释放，不得只堆砌电影感形容词。
```

## 102. 观众理解优先于镜头炫技

运镜有动机才成立。凡是不能增强空间理解、情绪推进、信息揭示、角色关系或节奏变化的运镜，都应降低优先级。

### 102.1 运镜动机审查

```text
推近：让观众靠近人物情绪、压力、秘密或危险。
拉远：揭示孤立、代价、环境压迫或真相全貌。
横移：展示人物关系变化、跟随行动、揭露被遮挡信息。
环绕：表现围困、亲密、失控、权力变化或心理旋涡。
升降：改变人物与环境的权力关系，或揭示空间规模。
手持：强化临场、慌乱、主观、不稳定。
静止：让观众被迫观察动作、对白和表情，不被镜头运动转移。
```

### 102.2 AI 输出自检

每个镜头生成后问三句：

```text
1. 这个运镜让剧情信息更清楚了吗？
2. 这个运镜让情绪更强了吗？
3. 如果去掉这个运镜，观众理解会不会变差？
```

如果三个答案都是否，改成固定镜头或更简单的推拉摇移。

### 102.3 长镜头和一整页分镜

长镜头、一镜到底、整页分镜尤其容易出现“看起来很大但信息不完整”。规则如下：

- 长镜头必须有内部节拍，不能只写“持续跟拍”。
- 一整页分镜必须有阅读顺序，不能只写“宏大构图”。
- 所有对白必须完整保留，所有关键动作必须可见。
- 若画面空间不够，优先增加文字说明或拆分局部说明，不删剧情。

## 103. 最终整合版提示词

下面这段可以作为“导演思维 + 运镜 + 拉片参考”的长版系统提示词，适合放入剧本转分镜模块：

```text
你是一名具备导演、摄影、剪辑和漫画 storyboard 思维的分镜设计师。请把用户剧本转为可执行分镜，不得遗漏任何对白、关键动作、因果线索、道具信息和情绪变化。剧情信息优先于画面装饰，必要时可以适当增加文字篇幅，把动作和情节完整交代清楚。

处理流程：
1. 先提取角色、场景、道具、冲突、对白、动作、情绪转折和因果线索。
2. 建立连续性记忆表：角色外观、服装、站位、道具状态、空间轴线、上一镜结束动作、下一镜起始动作。
3. 按 coverage 思维设计每个场景：空间交代镜头、主要动作/对白镜头、反应镜头、关键道具/线索插入镜头、转场钩子。
4. 每个镜头必须写清：剧情功能、景别、角度、构图、主体动作、摄影机运动、光线/声音、对白、观众注意点、转场方式、连续性。
5. 主体运动和摄影机运动必须分开写。不要用“电影感、高级、震撼”替代具体画面。
6. 对话场景保持 180 度轴线、视线匹配和正反打关系；动作场景保留准备、发生、结果、反应。
7. 如果某个分镜是一整页，整页尺寸由用户选择后固定；仍必须完整呈现动作、对白和剧情线索，不得为了构图省略内容。
8. 输出前自检：是否遗漏对白？是否遗漏动作结果？是否遗漏关键道具？是否有观众注意点？是否有转场钩子？是否能从上一镜自然接到下一镜？
```

这段提示词的定位是“强约束骨架”，后续可以叠加具体题材风格、画幅尺寸、镜头数量、漫画页格式或视频时长要求。

## 104. 近年 AI 多镜头资料带来的增量结论

2024-2026 年的视频生成研究逐渐从“单镜头好看”转向“多镜头可控叙事”。对插件最有用的结论不是模型结构，而是提示词和数据结构设计。

### 104.1 从 CameraCtrl 得到的规则

CameraCtrl 的核心启发是：摄影机姿态和轨迹应被明确表达，镜头运动不是装饰，而是叙事语言。

插件规则：

```text
每个镜头的摄影机运动必须可执行：固定、推近、拉远、横移、跟拍、摇、俯仰、升降、环绕等只能选必要项；若选择运动，必须写出运动起点、终点和叙事目的。
```

### 104.2 从 MotionCtrl / Direct-a-Video 得到的规则

这类资料反复强调 camera motion 和 object motion 应解耦。

插件规则：

```text
主体动作：人物或物体实际怎么动。
摄影机运动：镜头如何观察这个动作。
画面结果：运动结束后观众获得什么信息。
```

不要写：

```text
镜头快速移动，人物冲突激烈。
```

要写：

```text
主体动作：林夏后退半步，把碎屏手机藏到身后。
摄影机运动：低机位缓慢推近到她紧绷的手指。
画面结果：观众注意到手机屏幕仍在亮，暗示证据没有消失。
```

### 104.3 从 StoryBlender 得到的规则

StoryBlender 强调跨镜头一致性、空间连续和可编辑性。对剧本转分镜来说，应先建立“故事资产”和“镜头变量”的区别。

```text
故事资产：角色身份、服装、道具、场景结构、空间方向，跨镜头保持稳定。
镜头变量：景别、角度、镜头运动、当前动作、当前情绪、光线变化，可随剧情变化。
```

插件规则：输出分镜前先列资产表；每个 shot 只改变该镜头需要变化的变量，不能让角色服装、道具归属、空间方向无故漂移。

### 104.4 从 Camera Artist 得到的规则

Camera Artist 的启发是：分镜不是一次性罗列，而应递归修正相邻镜头关系。

插件规则：

```text
生成初稿后，必须做相邻镜头检查：
上一镜结束动作能否接到下一镜起始动作？
上一镜观众注意点能否自然转到下一镜？
人物方向、视线和站位是否冲突？
对白是否有说话者和听话者的情绪反馈？
```

### 104.5 从 ShotDirector 得到的规则

ShotDirector 把“转场”和“剪辑模式”作为多镜头生成的重点。对插件来说，每个镜头不能只写画面，还要写剪辑意图。

```text
剪辑意图：连续动作剪辑 / 视线匹配 / 图形匹配 / 声音桥 / 遮挡转场 / 情绪反差切 / 信息揭示切。
```

### 104.6 从 ShotStream 得到的规则

ShotStream 的启发是：长叙事需要历史上下文，而不是每个镜头孤立生成。插件可模拟“全局记忆 + 局部记忆”：

```text
全局记忆：角色、场景、核心冲突、道具状态、已经公开的信息、尚未公开的悬念。
局部记忆：当前场景内上一镜的动作、站位、情绪、对白、光线和声音。
```

每次生成新镜头时，先读取局部记忆；每个场景结束后，更新全局记忆。

## 105. 拉片结果如何反哺提示词

拉片不是收集术语，而是把成功镜头背后的决策转成可复用规则。建议将每次拉片整理成下面格式，方便后续喂给剧本转分镜模块。

```text
片段名称：
场景功能：
观众需要知道的信息：
人物情绪变化：
导演如何安排空间：
摄影机如何运动：
主体如何运动：
剪辑点在哪里：
声音如何参与叙事：
最值得复用的规则：
可转写成提示词的句子：
不适合照搬的部分：
```

### 105.1 示例转写

```text
拉片观察：角色没有直接说害怕，而是站在门口不进去；镜头从室内阴影慢慢推向门外亮处，观众先看到门框，再看到人物停住的脚。

提示词规则：不要只用台词说明情绪。优先用站位、停顿、手部动作、光线边界和镜头推进表现人物犹豫；对白只补充信息，不替代画面动作。
```

### 105.2 进入插件的方式

```text
当用户提供参考拉片资料时，请先提取其中可复用的导演规则，而不是模仿具体镜头表面。把规则应用到当前剧本的情绪、场景和人物关系中，保持原创剧情和角色一致性。

## 107. 线上来源到插件规则的对应表

这张表用于判断哪些外部资料值得进入 `screenplay_reference` 或系统提示词。

```text
CameraCtrl
可用点：摄影机姿态和轨迹控制。
插件规则：镜头运动要写起点、终点、方向、速度和叙事目的。

MotionCtrl
可用点：camera motion 与 object motion 分离控制。
插件规则：每镜分开写主体动作、摄影机运动和画面结果。

Direct-a-Video
可用点：用户可分别指定多个对象运动和镜头 pan/zoom。
插件规则：多人、多物、多方向运动必须逐项列出，不能混成一句。

ShotDirector
可用点：多镜头视频应有导演意图、场景感知和剪辑/转场设计。
插件规则：每镜输出转场钩子和剪辑意图。

Camera Artist
可用点：storyboard 与 cinematic language 结合，强调相邻镜头连续性。
插件规则：先检查 shot-to-shot，再优化单镜头画面。

StoryBlender / ShotStream
可用点：长叙事、多镜头需要历史记忆和可编辑结构。
插件规则：维护全局记忆、局部记忆、故事资产和镜头变量。

Prose Storyboard Language
可用点：用结构化自然语言描述和导演镜头。
插件规则：一镜一意，字段清楚，避免把多个镜头塞进一段。

StudioBinder / Boords / Yale Film Analysis Guide
可用点：景别、角度、运镜、构图、剪辑和拉片分析的基础术语。
插件规则：专业术语后必须跟具体画面动作，避免空泛“电影感”。
```

### 107.1 最适合进入系统提示词的规则

```text
1. 不遗漏对白、动作、道具、因果线索和情绪变化。
2. 主体运动与摄影机运动分开写。
3. 每镜必须有剧情功能、观众注意点、连续性和转场钩子。
4. 每个场景按 coverage 输出：空间交代、核心动作/对白、反应、插入、转场。
5. 整页分镜尺寸由用户选择后固定，但内容完整性优先。
```

### 107.2 更适合进入参考库而不是硬规则的内容

```text
1. 具体影片拉片案例。
2. 某一导演的个人风格。
3. 某一类型片的固定套路。
4. 复杂论文术语和模型结构。
5. 过长的电影理论解释。
```

原因：系统提示词应稳定、短、强约束；参考库可以长一些，用来提供风格、案例和可选镜头方案。

## 108. 剧本转分镜推荐输出 Schema

为了让导演思维稳定进入插件，建议不要只输出自然语言段落，而是先输出结构化字段，再附自然语言画面描述。

### 108.1 场景级字段

```text
scene_id：场景编号
scene_title：场景标题
time_and_place：时间与地点
dramatic_goal：本场戏的剧情目的
conflict：本场核心冲突
characters：出场角色与当前状态
props：关键道具与状态
space_axis：空间轴线和人物相对方位
coverage_plan：主镜头、对白/动作镜头、反应镜头、插入镜头、转场镜头
continuity_memory：承接上一场的角色、道具、情绪和空间信息
```

### 108.2 镜头级字段

```text
shot_id：镜头编号
shot_function：剧情功能
panel_size：分镜尺寸；如果是一整页，使用用户选择的固定尺寸
duration_or_panel_weight：时长或漫画页权重
shot_size：景别
camera_angle：角度
composition：构图和视觉中心
subject_action：主体动作
camera_motion：摄影机运动
dialogue：完整对白，不得漏写
sound：环境声、音效、声音桥或停顿
lighting：光线方向、明暗和色温
viewer_attention：观众注意点
continuity：与上一镜/下一镜的连续性
transition：剪辑点或转场钩子
image_prompt：用于生图/生视频的画面提示词
negative_prompt：避免事项
self_check：对白、动作、因果、道具、情绪是否完整
```

### 108.3 自然语言画面描述模板

```text
镜头 {shot_id}｜{shot_function}
画面：{shot_size}，{camera_angle}，{composition}。{subject_action}。
运镜：{camera_motion}，运动目的为 {movement_motivation}。
对白：{dialogue}
声音/光线：{sound}；{lighting}
观众注意点：{viewer_attention}
连续性与转场：{continuity}；{transition}
生图提示词：{image_prompt}
```

### 108.4 输出自检字段

```text
dialogue_complete：是否完整保留对白
action_complete：是否完整保留动作过程和结果
causality_complete：是否保留因果线索
props_visible：关键道具是否可见
emotion_visible：情绪变化是否通过表情/动作/构图呈现
camera_motivated：运镜是否有剧情动机
transition_ready：是否能接到下一镜
page_size_fixed：整页分镜是否使用用户选择尺寸
```

## 109. 三种输出档位

插件可以给用户三个档位，避免所有项目都输出过长。

### 109.1 快速档

适合短视频、草稿、批量生成。

```text
每镜输出：剧情功能、景别、动作、对白、运镜、转场。
```

### 109.2 标准档

适合漫画分镜和文生视频。

```text
每镜输出：剧情功能、景别、角度、构图、主体动作、摄影机运动、对白、观众注意点、连续性、转场、生图提示词。
```

### 109.3 专业档

适合长剧情、复杂动作戏、多角色对话和正式制作。

```text
先输出场景级连续性记忆和 coverage plan；再逐镜输出完整字段；最后输出自检表和遗漏修正建议。
```

建议默认使用“标准档”，把“专业档”作为高级选项。

## 110. 最终验收清单

整理完任何导演思维/运镜/拉片参考后，用这张清单判断能不能进入正式插件。

```text
1. 是否能直接提升剧本转分镜质量？
2. 是否能减少遗漏对白、动作、因果和道具？
3. 是否能减少空泛电影感形容词？
4. 是否能指导镜头之间的连续性？
5. 是否能指导整页分镜尺寸固定后的内容完整性？
6. 是否能转成明确字段或提示词？
7. 是否不会把用户剧本改写成另一个故事？
8. 是否不会强迫所有题材都使用同一种风格？
```

通过标准：至少满足 1、2、4、6；否则只放入参考库，不放入系统提示词。

## 111. 提示词注入顺序

导演思维参考文档很长，不能全部无差别塞进一次请求。建议按“硬规则优先、参考资料后置、风格最后”的顺序注入。

### 111.1 推荐顺序

```text
1. 系统硬规则：不得遗漏对白、动作、因果、道具、情绪；整页尺寸由用户选择并固定。
2. 输出结构：场景字段、镜头字段、自检字段。
3. 当前剧本：用户输入的完整剧情、对白和人物设定。
4. 连续性记忆：角色、空间、道具、动作和情绪状态。
5. 导演思维参考：coverage、运镜动机、观众注意点、剪辑转场。
6. 风格参考：题材、导演感、漫画风格、画面质感。
7. 最终自检：遗漏检查、连续性检查、尺寸检查、转场检查。
```

### 111.2 不推荐顺序

```text
1. 先给大量电影理论。
2. 再给用户剧本。
3. 最后轻描淡写说“不要遗漏”。
```

这种顺序容易让模型沉迷术语，反而漏掉对白和剧情。

### 111.3 长参考文档的摘取方式

```text
如果用户提供长参考文档，请只摘取与当前任务相关的规则：
对话戏：轴线、正反打、反应镜头、对白完整性。
动作戏：动作因果、主体运动、摄影机运动、结果反应。
悬疑戏：线索插入、遮挡、视线引导、信息延迟。
整页漫画：阅读顺序、主视觉、对白区、固定尺寸、剧情完整。
文生视频：镜头时长、运动可控、转场钩子、主体/镜头分离。
```

## 112. 防止过度提示词化

提示词越长不一定越好。导演思维资料应服务“稳定输出”，不是把模型压成电影术语复读。

### 112.1 应该硬编码的内容

- 不遗漏对白、动作、因果、道具和情绪。
- 一整页分镜尺寸由用户选择后固定。
- 主体运动与摄影机运动分开写。
- 每镜保留剧情功能、观众注意点、连续性和转场。
- 每个场景具备 coverage。

### 112.2 应该作为可选参考的内容

- 某个导演风格。
- 某部影片拉片。
- 某类复杂运镜。
- 某种构图审美。
- 某篇论文的技术细节。

### 112.3 应该避免的内容

```text
空泛词：高级、大片感、震撼、氛围拉满、电影级。
无动机运镜：镜头疯狂旋转、复杂运镜、炫酷转场。
压缩剧情：省略对白、合并关键动作、跳过道具线索。
伪专业：只堆英文术语，不写具体画面。
```

### 112.4 插件默认策略

```text
默认输出标准档。
只有用户选择“专业分镜/长剧情/复杂动作戏/多角色对话”时，才启用完整导演思维参考。
如果用户只要快速草稿，则保留硬规则和基本字段，不注入长篇理论。
```

## 113. 分镜尺寸选择菜单建议

如果一个分镜是一整页，整页尺寸不应由模型自行猜测，应由用户在生成前选择。插件只负责提供清晰选项，并在后续所有相关镜头中保持固定。

### 113.1 推荐尺寸选项

```text
漫画竖版页：2:3 / 3:4，适合传统漫画页、条漫封面页、完整大场面。
手机短视频：9:16，适合文生视频、短剧、竖屏动态分镜。
横屏影视：16:9，适合影视分镜、横屏视频、宽银幕场景。
社媒方图：1:1，适合平台封面、单图传播、角色展示。
宽幅横构图：21:9，适合大场面、追逐、空间压迫、群像调度。
自定义尺寸：用户输入宽高或比例，插件记录并锁定。
```

### 113.2 用户选择后的锁定规则

```text
page_size_user_selected：用户选择的尺寸或比例
page_size_locked：true
applies_to：整页分镜 / 当前场景 / 全部镜头
layout_priority：剧情完整 > 阅读顺序 > 人物动作 > 对白区域 > 构图美感
```

### 113.3 提示词写法

```text
本次整页分镜使用用户选择的固定尺寸：{page_size_user_selected}。生成过程中不得自行改变比例。请在该尺寸内完整呈现所有关键动作、对白、因果线索和人物情绪；如果画面元素较多，允许增加分镜文字说明，不允许删除剧情内容。
```

### 113.4 UI 建议

```text
尺寸选择应出现在生成前，而不是生成后。
如果用户选择“整页分镜”，必须要求选择尺寸。
如果用户选择“自动拆分多格”，尺寸可以作为整页画布比例，每格内部根据剧情权重自动分配。
如果用户选择“文生视频分镜”，默认推荐 9:16 或 16:9，由用户确认。
```

## 115. 剪辑连续性硬规则

分镜不是单张图列表，必须能剪起来。连续性剪辑资料里最值得进入插件的是下面几条。

### 115.1 建立空间

```text
每个新场景开始时，优先给空间交代：人物在哪里、谁和谁相对、入口出口在哪里、关键道具在哪里。
```

如果跳过空间交代，后续正反打、动作方向和追逐路线容易混乱。

### 115.2 视线匹配

```text
当人物看向画外时，下一镜应交代他/她在看什么，或明确保留悬念。
```

用于 AI 分镜时，要写：

```text
上一镜结束于林夏看向画外右侧；下一镜切到右侧墙角的监控摄像头，完成视线匹配。
```

### 115.3 动作匹配

```text
如果一个动作跨镜头，下一镜必须承接同一动作阶段、方向和节奏。
```

例如开门、转身、递物、奔跑、挥手、掏手机，都要写清上一镜结束姿势和下一镜起始姿势。

### 115.4 插入镜头

```text
插入镜头用于强调主镜头里已经存在但需要观众特别注意的信息，如手机屏幕、钥匙、伤口、合同、金额、门牌、手部动作。
```

插件规则：凡是影响剧情判断的物件，至少给一次插入镜头或特写；不能只在对白里提到。

### 115.5 切出镜头

```text
切出镜头用于补充主镜头之外的信息，如围观者反应、窗外警灯、监控视角、远处脚步、人群骚动。
```

插件规则：当需要压缩时间、转移空间、隐藏动作过程或制造悬念时，优先使用切出镜头。

### 115.6 声音桥

```text
声音可以先于画面出现，也可以跨镜头延续，用来平滑转场或提前提示下一信息点。
```

提示词写法：

```text
上一镜末尾传来门铃声，声音延续到下一镜门把手特写，形成声音桥。
```

### 115.7 进入自动自检

```text
空间是否交代？
视线是否匹配？
动作是否接得上？
关键道具是否给了插入镜头？
是否有必要的反应镜头？
是否有声音桥或转场钩子？
```

## 116. 分镜输出评分表

后续测试插件时，可以用这张表对比“直接转分镜”和“参考导演思维文档转分镜”的输出质量。

```text
对白完整性：0-10 分，是否不遗漏任何对白，是否标明说话者。
动作完整性：0-10 分，是否完整呈现动作准备、发生、结果和反应。
因果清晰度：0-10 分，观众是否能理解事件为什么发生、后果是什么。
道具线索：0-10 分，关键道具是否可见，是否有插入镜头或特写。
情绪表达：0-10 分，情绪是否通过表情、动作、构图、停顿或声音呈现。
运镜动机：0-10 分，摄影机运动是否服务剧情，而非空泛炫技。
主体/镜头分离：0-10 分，主体运动和摄影机运动是否分开写清。
连续性：0-10 分，人物站位、视线、动作、道具状态是否前后相接。
coverage 完整度：0-10 分，是否有空间交代、动作/对白、反应、插入、转场。
观众注意点：0-10 分，每镜是否说明观众先看什么、如何转移注意力。
整页尺寸规则：0-10 分，整页分镜是否使用用户选择的固定尺寸并完整呈现剧情。
可执行性：0-10 分，生图/生视频提示词是否具体、清楚、可落地。
```

### 116.1 评分解释

```text
90-120 分：可进入正式生成。
70-89 分：结构基本可用，需要补遗漏或连续性。
50-69 分：镜头语言有雏形，但剧情或对白可能不完整。
50 分以下：更像画面描述，不适合作为正式分镜。
```

### 116.2 对比测试建议

```text
同一段剧本分别跑两次：
版本 A：不注入导演思维参考。
版本 B：注入本文件中的最短强约束提示词 + coverage + 连续性记忆 + 尺寸选择规则。

对比重点：
1. 是否少漏对白。
2. 是否少漏动作结果。
3. 是否更清楚地描述主体运动和摄影机运动。
4. 是否有反应镜头、插入镜头和转场钩子。
5. 整页分镜是否固定用户选择尺寸并保留剧情完整。
```

## 117. 2026 连续性 storyboard 新资料补充

最新 storyboard 生成资料继续强化同一个结论：长剧情不是单张美图拼接，而是角色、场景、道具、动作和转场的长程一致性。

### 117.1 CANVAS

资料方向：Continuity-Aware Narratives via Visual Agentic Storyboarding。
可迁移规则：

```text
长故事分镜应显式维护角色连续性、背景锚点和地点感知的场景规划。插件中可对应为角色记忆、空间记忆、道具记忆和转场记忆。
```

### 117.2 DreamShot

资料方向：Personalized Storyboard Synthesis with Video Diffusion Prior。
可迁移规则：

```text
多镜头 storyboard 需要角色身份一致、场景连贯和叙事流动。插件中可要求用户上传或确认角色参考，并在每个镜头复用角色外观、服装和标志物。
```

### 117.3 对插件的补充建议

```text
如果剧本超过一个场景，先生成“故事连续性总表”。
如果角色反复出现，保留“角色参考描述”并逐镜复用。
如果场景反复出现，保留“背景锚点”：门、窗、柜台、街角、灯牌、监控、沙发等。
如果关键道具跨镜头出现，记录道具状态变化：出现、被拿起、损坏、藏起、转交、丢失。
```
